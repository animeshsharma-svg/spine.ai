📼 Recorded flows

real API traffic → test cases with field validations ← dashboard

Do a flow once in the browser with recording on, and every /api/* call it fired is captured (the access token is never written to disk). Here that recording becomes proper test cases with a Postman-style checklist — each field the request sent, each field the response returned, and each value that came back exactly as sent. Replay reads live to turn every check into a real ✅ / ❌ with a fresh token. Mutations are shown from the capture and never fired against live data.

Pick a recording and press Convert.
