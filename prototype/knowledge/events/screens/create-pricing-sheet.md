## What each control on create-pricing-sheet does

- **Ask Clara** (button): Clicking it opens Clara for help with generating or reviewing the event. Affects: It may use the event's line items as input for an AI RFP request.. Leads to: Clara panel or dialog. Rule R-FCR-042-4. Check: With line items present, click Ask Clara and verify that the Clara interface opens.
- **Add Attachments** (button): Clicking it opens an attachment control so files can be added to the event. Affects: It adds attachment data to the event configuration.. Leads to: Attachment picker or drawer. Check: Click Add Attachments and verify that a file-selection control appears.
- **Add T&Cs** (button): Clicking it opens the terms-and-conditions editor. Affects: It changes the event's terms and conditions, including clauses or attachments.. Leads to: Terms-and-conditions drawer or dialog. Rule R-FCR-008-3. Check: Click Add T&Cs and verify that the terms editor opens.
- **Items 2** (button): Clicking it opens the event's two-item line-item view or editor. Affects: It exposes the line items that are saved in the event payload.. Leads to: Line-item drawer or section. Rule R-FCR-008-1. Check: Verify that clicking Items 2 displays two event line items.
- **Save as draft** (button): Clicking it saves the current event as a draft. Affects: It creates or updates the draft event record and preserves draft stage and line-item data.. Leads to: Draft event state, usually remaining on this screen. Rule R-FCR-014-4. Check: Click Save as draft, reload the event, and verify that the entered data remains and the event is still a draft.
- **Publish** (button): Clicking it validates and publishes the RFQ event. Affects: It changes the event or project from draft toward an active published state and may create or update its stages.. Leads to: Published event or event details screen. Rule R-FCR-017-1. Check: With all required data and at least one participant entered, click Publish and verify that the event is created successfully.
- **RFQ** (button): Clicking it selects or opens the RFQ event mode. Affects: It determines that this stage uses request-for-quotation behavior rather than another event mode.. Leads to: RFQ configuration or stays here. Check: Verify that RFQ is shown as the active event mode after selection.
- **Buy Template** (button): Clicking it opens the template selector for choosing a buy template. Affects: It changes the template and can replace the fields and configuration available in the pricing sheet.. Leads to: Template-selection dialog or drawer. Rule R-FCR-026-4. Check: Choose a different template and verify that the template fields or configuration change.
- **Add Columns** (button): Clicking it opens controls for adding or configuring pricing-sheet columns. Affects: It changes the fields or columns shown for each event line item.. Leads to: Column-selection drawer or dialog. Check: Add a column and verify that it appears in the pricing sheet.
- **Details** (button): Clicking it opens the event details section. Affects: It changes the visible configuration area but does not by itself change event data.. Leads to: Details drawer or section. Check: Click Details and verify that event-detail fields are displayed.
- **Price Components** (button): Clicking it opens the price-components configuration. Affects: It changes how the event's price is broken into component fields or calculations.. Leads to: Price-components drawer or section. Check: Click Price Components and verify that price-component controls are displayed.
- **Invite Vendor** (button): Clicking it opens the vendor invitation control. Affects: It adds selected vendor companies to the event audience or participant list.. Leads to: Invite-vendor drawer or dialog. Rule R-FCR-035-3. Check: Select an eligible vendor and verify that the vendor appears in the participant list.
- **Participants** (button): Clicking it opens the event participant list and management controls. Affects: It changes the event's audience participants when vendors are added or removed.. Leads to: Participants drawer or dialog. Rule R-FCR-008-1. Check: Open Participants and verify that the current invited-vendor list is shown.
- **Savings** (button): Clicking it opens the savings configuration or summary. Affects: It changes or displays savings data associated with the event.. Leads to: Savings drawer or section. Check: Scroll to Savings, click it, and verify that savings fields or values are displayed.
- **Terms & Conditions** (button): Clicking it opens the terms-and-conditions section. Affects: It changes the clauses and attachments stored for the event's terms and conditions.. Leads to: Terms-and-conditions drawer or section. Rule R-FCR-008-3. Check: Click Terms & Conditions and verify that the configured clauses or attachments are shown.
- **Now - 04:32 pm, 21st Oct ( 30 Mins )** (button): Clicking it opens the event schedule control showing the start time, end time, and duration. Affects: It changes the stage schedule and therefore when vendors can respond.. Leads to: Schedule drawer or popover. Rule R-FCR-020-3. - **Technical Stage** (tab): Clicking it selects the Technical Stage tab. Affects: It changes the active stage being configured without changing event data by itself.. Leads to: Technical Stage screen. Rule R-FLA-016-2. Check: Click Technical Stage and verify that its fields and configuration are displayed.
- **RFQ** (tab): Clicking it selects or keeps the RFQ stage active. Affects: It changes the active stage context to the RFQ stage without changing data by itself.. Leads to: RFQ screen, staying here when already selected. Rule R-FLA-016-2. Check: Verify that RFQ remains visually selected and its pricing-sheet fields are shown.

- **Product** (column): Filling the required Product column sets the product for the line item. Affects: It changes the line item's product_uuid and is required for saving or publishing the event.. - **Product Variant** (column): Filling the required Product Variant column sets the product variant or quality for the line item. Affects: It changes the line item's product_quality_uuid and is required when the template uses the field.. Leads to: Variant selector or stays here. Rule R-FCR-008-1. - **Quantity Requested** (column): Filling the required Quantity Requested column sets the quantity requested for the line item. ## Test cases written from the create-pricing-sheet screen

- GEN-SCR-090: Add Columns opens the column selection view. Steps: Click Add Columns. Expected: A column selection interface opens. The existing pricing-sheet columns remain visible and additional available columns can be reviewed. [plan: partial]
- GEN-SCR-091: Required pricing-sheet columns are marked. Steps: Inspect the column headers. Compare the required markers on each column. Expected: Product, Product Variant, Quantity Requested, Delivery location, Price, Quantity Available, and Total Amount show required markers. GST does not show a required marker. [plan: partial]
- GEN-SCR-092: Saving a draft updates the existing draft instead of creating a duplicate. Steps: Enter a unique value in Enter the title of the project. Click Save as draft. Wait for the save to complete. Change the value in Enter the title of the project. Click Save as draft again. Expected: The first save creates one draft. The second save updates the same draft with the new title and does not create a second draft. [plan: partial]
- GEN-SCR-093: Publish shows the schedule confirmation before completion. Steps: Click Publish. Do not confirm the publish action. Expected: A publish confirmation appears. It shows "Starts on: Now" and an ending time with the 30-minute duration, including the event's vendor and schedule summary. The event is not published until the confirmation is completed. [plan: partial]
- GEN-SCR-213: Publish refuses a project without participants. Steps: Click "Publish". Expected: Publishing stops and the app shows "Please add participants to proceed!". [plan: full]
- GEN-SCR-214: Save as draft creates the initial draft event. Steps: Click "Save as draft". Expected: The event is saved as a draft. The draft retains the entered title and line-item values. [plan: partial]
- GEN-SCR-215: Changing the selected template asks for confirmation. Steps: Click "Buy Template". Choose a different template. Stop at the confirmation dialog. Expected: The confirmation dialog shows "Changing template will reset data. Are you sure?" and the confirmation action is labeled "Yes". [plan: partial]
- GEN-SCR-216: Pricing sheet navigation controls open their sections. Steps: Click "Items 2" and verify the item section opens. Close the item section. Click "Add Columns" and verify the column selector opens. Close the column selector. Click "Add Attachments" and verify the attachment area opens. Close the attachment area. Click "Add T&Cs" and verify the terms editor opens. Close the terms editor. Click each of "Details", "Price Components", "Participants", "Savings", and "Terms & Conditions". Click "Now - 02:33 am, 21st Oct ( 30 Mins )" and verify the schedule editor opens. Expected: Each control opens its matching section or editor without navigating away from the create-pricing-sheet screen. [plan: partial]
- GEN-SCR-330: Save as draft creates a draft event with line items. Steps: Enter a project title in "Enter the title of the project". Verify the line-item values under "Product", "Product Variant", "Quantity Requested", "Delivery location", "Price", "Quantity Available", and "Total Amount". Click "Save as draft". Expected: The event is saved as a draft. The first save sends a POST request to the event-groups endpoint with status "draft", the project title, and the line items. A later save uses PATCH for the event group. [plan: partial]
- GEN-SCR-331: Add Columns opens the column selection control. Steps: Click "Add Columns". Expected: A column selection or configuration panel opens for the pricing sheet. [plan: full]
