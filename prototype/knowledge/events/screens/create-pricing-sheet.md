## Test cases written from the create-pricing-sheet screen

- GEN-SCR-090: Add Columns opens the column selection view. Steps: Click Add Columns. Expected: A column selection interface opens. The existing pricing-sheet columns remain visible and additional available columns can be reviewed. [plan: partial]
- GEN-SCR-091: Required pricing-sheet columns are marked. Steps: Inspect the column headers. Compare the required markers on each column. Expected: Product, Product Variant, Quantity Requested, Delivery location, Price, Quantity Available, and Total Amount show required markers. GST does not show a required marker. [plan: partial]
- GEN-SCR-092: Saving a draft updates the existing draft instead of creating a duplicate. Steps: Enter a unique value in Enter the title of the project. Click Save as draft. Wait for the save to complete. Change the value in Enter the title of the project. Click Save as draft again. Expected: The first save creates one draft. The second save updates the same draft with the new title and does not create a second draft. [plan: partial]
- GEN-SCR-093: Publish shows the schedule confirmation before completion. Steps: Click Publish. Do not confirm the publish action. Expected: A publish confirmation appears. It shows "Starts on: Now" and an ending time with the 30-minute duration, including the event's vendor and schedule summary. The event is not published until the confirmation is completed. [plan: partial]
