## What each control on single-stage-configured-auction does

- **Ask Clara** (button): It opens the Clara assistant for generating or reviewing event content. Affects: It can add AI-generated RFP questions to the event when line items are present.. Leads to: Clara assistant panel.. Rule R-FCR-042-4. Check: Click Ask Clara and verify that the Clara panel opens.
- **Rank on lot** (button): It opens the event strategy configuration for ranking bids on lots. Affects: It changes the event's closing and ranking configuration when the setting is saved.. Leads to: Strategy configuration drawer.. Rule R-FCR-033-1. Check: Click Rank on lot and verify that the strategy configuration opens with lot-based ranking selected.
- **Select Templates** (button): It opens the template picker for selecting a commercial template. Affects: It changes the stage template and can reset existing stage data after confirmation when replacing a template.. Leads to: Template picker.. Rule R-FCR-026-4. Check: Click Select Templates and verify that the template list and selection controls appear.
- **Participants** (button): It opens the participant management control. Affects: It changes the event's invited vendor records and the participant count used by later publish validation.. Leads to: Participants drawer.. Rule R-FCR-017-1. Check: Click Participants and verify that vendors can be viewed or managed.
- **Terms & Conditions** (button, disabled): Does nothing because the Terms & Conditions button is disabled. Affects: Nothing; payment terms and conditions cannot be edited from this control while disabled.. Leads to: stays here. Rule R-FCR-039-3. Check: Verify that clicking the disabled button does not open a terms editor.
- **Publish Event** (button, disabled): The disabled Publish Event button cannot submit the event. Affects: The event remains unpublished and no event record or invitations are created.. Leads to: stays here.. Rule R-FCR-016-2. Check: Verify that Publish Event is disabled and clicking it does not submit the event.
- **Events** (link): It navigates away from the create screen to the Events area. Affects: nothing. Leads to: Events screen. Check: Click Events and verify that the Events screen loads.
- **Enter the title of this event** (field): It lets the buyer enter or edit the event title. Affects: It updates the event title and supplies the title value used by title validation during publish.. Leads to: stays here. Rule R-FCR-025-1. Check: Enter a title and verify that the field value changes and its title validation error clears.
- **Search vendors you want to add** (select, disabled): It is a disabled vendor search and selection control. Affects: nothing. Leads to: stays here. Rule R-FCR-035-3. Check: Verify that the vendor search cannot be focused or used and that no participant is added.
