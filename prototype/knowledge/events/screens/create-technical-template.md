## What each control on create-technical-template does

- **Ask Clara** (button): Clicking Ask Clara opens the AI question-generation flow for the technical stage. Affects: It can add AI-generated questions to the technical stage and requires project line items.. Leads to: AI question drawer or dialog. Rule R-FCR-042-4. Check: With at least one line item, click Ask Clara and verify that the AI question flow opens.
- **Add Attachments** (button): Clicking Add Attachments opens the attachment control for adding files. Affects: It changes the event's attachment data.. Leads to: Attachment picker or drawer. Check: Click Add Attachments and verify that a file can be selected or managed.
- **Add T&Cs** (button): Clicking Add T&Cs opens the terms and conditions editor. Affects: It changes the event's terms_and_conditions data.. Leads to: Terms and conditions drawer or dialog. Rule R-FCR-039-3. Check: Click Add T&Cs and verify that terms or attachments can be entered.
- **Items 0** (button): Clicking Items 0 opens the line-item management control. Affects: It allows the event's line items to be added or changed.. Leads to: Manage Line Items drawer or section. Check: Click Items 0 and verify that the line-item management view opens.
- **Save as draft** (button, disabled): The disabled Save as draft button cannot be clicked while the required line items are missing. Affects: It blocks saving the current event as a draft until line items are added.. Leads to: stays here. Rule R-FCR-016-2. Check: Verify that Save as draft is disabled and that adding a line item changes its availability.
- **Publish** (button): Clicking Publish validates the project and attempts to publish the event. Affects: It moves the event from creation into the publish flow and can activate its stages after all required data passes validation.. Leads to: Publish confirmation, validation error, or the published event. Rule R-FCR-019-2. Check: Complete all required fields and click Publish, then verify either the publish confirmation or a specific validation error.
- **Technical Stage** (button): It opens the Technical Stage configuration or details. Affects: It changes or exposes the technical-stage setup rather than the RFQ stage.. Leads to: Technical Stage configuration view. Check: Click Technical Stage and verify that technical-stage settings are shown.
- **Test** (button): Opens a test or preview of the technical stage. Affects: Does not publish the event, but lets the buyer inspect the configured technical-stage experience.. Leads to: Technical-stage test or preview screen. Check: Click Test and verify that a test or preview view opens without publishing the event.
- **Add Evaluator** (button): Clicking Add Evaluator opens a picker for assigning an evaluator to the technical assessment. Affects: It adds or changes the evaluator required for the technical stage or its section.. Leads to: Evaluator picker. Rule R-FCR-041-4. Check: Click Add Evaluator, select an evaluator, and verify that the evaluator appears on the technical stage.
- **Participants** (button): Clicking Participants opens the participant management control. Affects: It changes the vendors invited to or allowed to bid in the event.. Leads to: Participants drawer or section. Rule R-FCR-017-1. Check: Click Participants and verify that vendors can be searched, added, or removed.
- **Terms & Conditions** (button): Clicking Terms & Conditions opens the event's terms and conditions control. Affects: It changes the event's terms_and_conditions data and can satisfy a publish requirement.. Leads to: Terms and conditions drawer or section. Rule R-FCR-039-3. Check: Click Terms & Conditions and verify that the event terms can be viewed or edited.
- **Now - 04:32 pm, 21st Oct ( 30 Mins )** (button): Clicking the current schedule opens the event timing editor. Affects: It changes the stage start time, end time, duration, or recurrence settings.. Leads to: Schedule drawer. Rule R-FCR-022-7. Check: Click the displayed schedule and verify that the timing fields open for editing.
- **Technical Stage** (tab): The selected Technical Stage tab displays the technical assessment stage. Affects: It selects which stage's configuration and questions are shown.. Leads to: stays here. Rule R-FLA-016-2. Check: Verify that the Technical Stage tab is highlighted and its assessment content is visible.
- **RFQ** (tab): Clicking the RFQ tab switches the displayed stage to the RFQ stage. Affects: It changes the selected stage being configured without itself changing event data.. Leads to: RFQ stage view. Rule R-FLA-016-2. Check: Click RFQ and verify that the RFQ stage content becomes visible.
- **Events** (link): Clicking Events navigates back to the events list. Affects: nothing. Leads to: Events screen. Check: Click Events and verify that the events list is displayed.
- **Enter the title of the project** (field): Entering text in this field sets the project title. Affects: It changes the event group's title used during saving and publishing.. Leads to: stays here. Rule R-FCR-013-1. Check: Enter a title and verify that the field retains it and that publishing no longer reports an empty project title.
- **Search vendors you want to add** (select): Searching in this field filters vendors and selecting a result adds that vendor as a participant. Affects: It changes the event's audience or participant records, subject to vendor eligibility restrictions.. Leads to: Vendor search results or the participants list. Rule R-FCR-035-3. - **#** (column): The # column displays the line-item number. Affects: nothing. Leads to: stays here. Check: Verify that each displayed line item has a number in this column.

Affects: It identifies the required specification data for each line item.. Leads to: stays here. Check: Verify that the Specification header is visible and marked required.
