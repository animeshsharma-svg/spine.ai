## What each control on create-technical-template does

- **Ask Clara** (button): It opens Clara to help generate technical questions for the event. Affects: It can add AI-generated questions to the technical-stage data, but it requires project line items.. Leads to: Clara assistant drawer. Rule R-FCR-042-4. Check: Click Ask Clara and verify that the Clara interface opens or reports that line items are required.
- **Add Attachments** (button): It opens the attachment interface for adding files. Affects: It adds attachment records to the event when files are selected.. Leads to: Attachment picker or drawer. Check: Click Add Attachments and verify that a file-selection interface appears.
- **Add T&Cs** (button): It opens the terms-and-conditions interface. Affects: It changes the event terms-and-conditions data that is included when the event is saved or published.. Leads to: Terms-and-conditions drawer or dialog. Rule R-FCR-008-3. Check: Click Add T&Cs and verify that terms and conditions can be entered or selected.
- **Items 0** (button): It opens the line-items management interface. Affects: It changes the event line-item records used by the technical stage and later sourcing stages.. Leads to: Manage Line Items section. Check: Click Items 0 and verify that the line-item management view opens with no items listed.
- **Save as draft** (button, disabled): It cannot be clicked because the required line items have not been added. Affects: Nothing is saved while the control remains disabled.. Leads to: stays here. Rule R-FCR-016-2. Check: Verify that clicking Save as draft produces no action while Items shows 0.
- **Publish** (button): It validates the project and attempts to publish the event. Affects: A successful action activates the event and advances it to the published workflow, while validation errors block publication.. Leads to: Published event or validation error state. Rule R-FCR-017-1. Check: Click Publish and verify that the event is published only after required title, participants, line items, and stage configuration are valid.
- **Technical Stage** (button): It opens the Technical Stage configuration or details. Affects: It changes or exposes the technical-stage setup rather than the RFQ stage.. Leads to: Technical Stage configuration view. Check: Click Technical Stage and verify that technical-stage settings are shown.
- **Test** (button): Opens a test or preview of the technical stage. Affects: Does not publish the event, but lets the buyer inspect the configured technical-stage experience.. Leads to: Technical-stage test or preview screen. Check: Click Test and verify that a test or preview view opens without publishing the event.
- **Add Evaluator** (button): It opens evaluator selection for the technical stage. Affects: It assigns an evaluator to the stage or its line-item sections, which is required for technical evaluation.. Leads to: Evaluator selection drawer or dialog. Rule R-FCR-041-4. Check: Click Add Evaluator, select an evaluator, and verify that the evaluator appears in the technical-stage configuration.
- **Participants** (button): It opens the participant-management interface. Affects: It changes the vendor participants invited to the project.. Leads to: Participants drawer or section. Rule R-FCR-017-1. Check: Click Participants and verify that vendors can be searched, added, or removed.

## Test cases written from the create-technical-template screen

- GEN-SCR-085: Save as draft is disabled without line items. Steps: Confirm that "Save as draft" cannot be clicked. Hover over "Save as draft". Expected: "Save as draft" remains disabled. A tooltip shows "Please add line items". [plan: full]
- GEN-SCR-086: Blacklisted and TNA vendors cannot be selected. Steps: Click "Participants". Open "Search vendors you want to add". View the blacklisted vendor and the TNA vendor in the results. Expected: The blacklisted vendor is disabled and marked "Blocked". The TNA vendor is disabled and marked "TNA". Neither vendor can be selected. [plan: partial]
- GEN-SCR-207: Publish refuses a project with no line items. Steps: Confirm "Items 0" is shown. Click "Publish". Expected: The event is not published. The app shows "Line Items are not added, please add them in Manage Line Items section". [plan: full]

- GEN-SCR-209: Publish refuses missing payment terms. Steps: Click "Publish". Expected: The event is not published. The app shows "Payment Terms and Conditions are mandatory". [plan: full]
