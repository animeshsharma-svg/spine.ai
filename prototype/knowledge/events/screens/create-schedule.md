## Test cases written from the create-schedule screen

- GEN-SCR-100: Publish confirmation shows the scheduled event summary. Steps: Click "Publish". Review the event summary in the confirmation dialog. Close the dialog without confirming. Expected: The summary shows "Starts on: Now", an ending time with the duration, and "Vendors invited:" with the de-duplicated vendor count. The displayed timing matches the event schedule. [plan: partial]
- GEN-SCR-101: Custom duration requires an end time before publishing. Steps: Close the duration popover. Click "Save Schedule". Click "Publish". Expected: "Save Schedule" accepts the schedule, but publishing is refused with exactly "Please add end time for the event". [plan: full]
- GEN-SCR-102: Back discards unsaved schedule changes. Steps: Change "Select time". Click "Back". Reopen the schedule screen without saving. Expected: The changed time is not retained. The schedule returns to its previously saved values. [plan: partial]
- GEN-SCR-103: Recurring configuration is copied to every stage. Steps: Select "Technical Stage". Turn on "Mark as Recurring EventSet this event to repeat automaticall". Configure the recurrence. Click "Save Schedule". Select "RFQ". Review the recurrence settings. Expected: The RFQ stage has the same recurring configuration as the Technical Stage, including the recurrence type, interval, and ending settings. [plan: full]
- GEN-SCR-104: Select date remains unavailable for a Now start. Steps: Review "Select date". Review "Select time". Change "Start now" to a scheduled start option. Expected: "Select date" is disabled while "Start now" is selected. After choosing a scheduled start option, the date and time controls become available for entry. [plan: full]
- GEN-SCR-221: Custom duration requires an end time before publishing. Steps: Select Custom duration from Duration. Leave the end time unset. Click Save Schedule. Click Publish. Expected: Save Schedule succeeds without requesting an end time. Publishing fails with "Please add end time for the event". [plan: full]
- GEN-SCR-222: Back discards unsaved schedule changes. Steps: Change the value in Enter the title of the project. Change Duration. Click Back. Reopen the same schedule. Expected: The schedule returns to the previous screen without saving the changes. Reopening it shows the original title and duration. [plan: none]
- GEN-SCR-223: The schedule chip shows the current start, end, and duration. Steps: Confirm that Start now is selected. Set Duration to a known duration. Observe the schedule chip. Wait at least 10 seconds and observe it again. Expected: The chip shows "Now - <end> (<duration>)". The end time reflects the current time plus the selected duration, and the chip refreshes as time advances. [plan: partial]
