## Test cases written from the create-schedule screen

- GEN-SCR-100: Publish confirmation shows the scheduled event summary. Steps: Click "Publish". Review the event summary in the confirmation dialog. Close the dialog without confirming. Expected: The summary shows "Starts on: Now", an ending time with the duration, and "Vendors invited:" with the de-duplicated vendor count. The displayed timing matches the event schedule. [plan: partial]
- GEN-SCR-101: Custom duration requires an end time before publishing. Steps: Close the duration popover. Click "Save Schedule". Click "Publish". Expected: "Save Schedule" accepts the schedule, but publishing is refused with exactly "Please add end time for the event". [plan: full]
- GEN-SCR-102: Back discards unsaved schedule changes. Steps: Change "Select time". Click "Back". Reopen the schedule screen without saving. Expected: The changed time is not retained. The schedule returns to its previously saved values. [plan: full]
- GEN-SCR-103: Recurring configuration is copied to every stage. Steps: Select "Technical Stage". Turn on "Mark as Recurring EventSet this event to repeat automaticall". Configure the recurrence. Click "Save Schedule". Select "RFQ". Review the recurrence settings. Expected: The RFQ stage has the same recurring configuration as the Technical Stage, including the recurrence type, interval, and ending settings. [plan: partial]
- GEN-SCR-104: Select date remains unavailable for a Now start. Steps: Review "Select date". Review "Select time". Change "Start now" to a scheduled start option. Expected: "Select date" is disabled while "Start now" is selected. After choosing a scheduled start option, the date and time controls become available for entry. [plan: full]
- GEN-SCR-221: Custom duration requires an end time before publishing. Steps: Select Custom duration from Duration. Leave the end time unset. Click Save Schedule. Click Publish. Expected: Save Schedule succeeds without requesting an end time. Publishing fails with "Please add end time for the event". [plan: full]
- GEN-SCR-222: Back discards unsaved schedule changes. Steps: Change the value in Enter the title of the project. Change Duration. Click Back. Reopen the same schedule. Expected: The schedule returns to the previous screen without saving the changes. Reopening it shows the original title and duration. [plan: full]
- GEN-SCR-223: The schedule chip shows the current start, end, and duration. Steps: Confirm that Start now is selected. Set Duration to a known duration. Observe the schedule chip. Wait at least 10 seconds and observe it again. Expected: The chip shows "Now - <end> (<duration>)". The end time reflects the current time plus the selected duration, and the chip refreshes as time advances. [plan: partial]
- GEN-SCR-335: Custom duration requires an end time when publishing. Steps: Open Duration. Choose Custom duration. Close the duration popover without entering an end time. Click Save Schedule. Click Publish and complete the displayed confirmation flow. Expected: Save Schedule succeeds. Publishing is refused with the exact message "Please add end time for the event". [plan: full]
- GEN-SCR-336: Fixed time enables date selection. Steps: Confirm Select date is disabled while Start now is selected. Open Start now. Choose Fixed time. Open Select date. Choose a date and set a time with Select time. Expected: Select date becomes enabled after Fixed time is selected. A date and time can be entered, and the schedule reflects the fixed start instead of Now. [plan: partial]
- GEN-SCR-337: Recurring event changes the publish action label. Steps: Turn on Mark as Recurring EventSet this event to repeat automaticall. Inspect Publish. Expected: The publish action label changes from "Publish" to "Save Recurring Event". [plan: full]
- GEN-SCR-338: Back discards unsaved schedule changes. Steps: Change the value in Enter the title of the project. Click Back. Return to the create schedule screen through Events. Expected: The unsaved title change is discarded. The previously saved project title remains. [plan: none]
- GEN-SCR-339: Save as draft preserves required project and line-item data. Steps: Enter a project title. Click Items 2. Verify values are present for Product, Product Variant, Quantity Requested, Delivery location, Price, Quantity Available, and Total Amount. Click Save as draft. Reopen the saved draft. Expected: The draft is saved and reopens with the entered project title and line-item values preserved. The initial save creates the draft rather than updating an existing draft. [plan: partial]
