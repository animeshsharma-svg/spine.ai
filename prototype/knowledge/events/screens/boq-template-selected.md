## What each control on boq-template-selected does

- **Ask Clara** (button): It opens the Clara assistance panel. Affects: It does not change event data.. Leads to: Clara summary panel. Rule R-FCR-011-5. Check: Click it and verify the Clara panel opens.
- **Add Attachments** (button): It opens an attachment picker for adding files to the event. Affects: It adds selected files to the event attachments.. Leads to: Attachment picker or drawer. Check: Add a file and verify it appears as an event attachment.
- **Add T&Cs** (button): It opens the terms and conditions editor. Affects: It changes the event's terms_and_conditions data.. Leads to: Terms and conditions drawer. Rule R-FCR-008-3. Check: Open it, add a clause, and verify the clause is shown in the editor.
- **Save as draft** (button, disabled): It remains disabled and cannot be clicked. Affects: It does not save or change the event.. Leads to: stays here. Rule R-FCR-016-1. Check: Verify the button is disabled and clicking it has no effect.
- **Publish** (button): It validates and publishes the configured event. Affects: It changes the event from draft configuration to a published event and starts the publish flow.. Leads to: Publish confirmation or the created event screen. Rule R-FCR-019-2. Check: Complete all required data, click Publish, and verify the event is created successfully.
- **Rank on lot** (button): It changes the auction ranking scope to rank bids on the lot. Affects: It changes the auction strategy and how bids are ranked.. Leads to: stays here. Rule R-FCR-009-1. Check: Click it and verify the ranking scope changes to lot-based ranking.
- **New BOQ 2** (button): It selects the BOQ stage named New BOQ 2. Affects: It changes the currently edited stage without changing project data by itself.. Leads to: New BOQ 2 stage view. Rule R-FLA-016-2. Check: Click it and verify the New BOQ 2 sheet is displayed.
- **Add Columns** (button): It opens the available column selector. Affects: It allows additional pricing-sheet columns to be added to the event line items.. Leads to: Column-selection menu or drawer. Rule R-FCR-027-4. Check: Open it and verify available columns are listed.
- **Upload Sheet** (button): It opens a sheet uploader for importing BOQ rows or values. Affects: It can replace or populate the current pricing-sheet line-item data from an uploaded file.. Leads to: Sheet upload dialog. Rule R-FCR-027-1. Check: Upload a valid sheet and verify its rows appear in the BOQ.
- **Add New** (button): It opens the menu for adding another pricing-sheet field. Affects: It adds a selected optional field or column to the sheet.. Leads to: Add-field menu. Rule R-FCR-027-4. Check: Open it and verify the available fields are shown.
- **Participants** (button): It opens the participant management view. Affects: It changes the event's participant or vendor audience records when vendors are added or removed.. Leads to: Participants drawer or screen. Rule R-FCR-017-1. Check: Click it and verify the participant list and management controls appear.
- **Terms & Conditions** (button): It opens the event's terms and conditions section. Affects: It changes the event's terms_and_conditions data when clauses or attachments are edited.. Leads to: Terms and conditions drawer or section. Rule R-FCR-008-3. Check: Click it and verify the terms and conditions editor is visible.
- **Now - 04:54 pm, 21st Oct ( 30 Mins )** (button): It opens the event schedule control for the displayed start or closing time and duration. Affects: It changes the event stage schedule, including its closing time or duration.. Leads to: Schedule drawer or popover. Rule R-FCR-022-7. Check: Open it and verify the displayed schedule values can be edited.
- **Auction** (tab): It keeps the event in Auction mode and displays the auction configuration. Affects: It selects the auction event mode and its associated strategy and bidding flow.. Leads to: Auction configuration view. Rule R-FCR-009-1. Check: Verify Auction is selected and auction-specific settings are visible.
- **Events** (link): It navigates back to the Events area. Affects: It does not change event data.. Leads to: Events screen. Check: Click it and verify the Events screen opens.
- **Enter the title of the project** (field): It accepts or edits the project title. Affects: It changes the event group's title used during saving and publishing.. Leads to: stays here. Rule R-FCR-013-1. Check: Enter a title and verify the value remains in the field.
- **Search vendors you want to add** (select): It searches for and adds vendors to the event audience. Affects: It changes the event's audience_company_uuids and participant records.. Leads to: stays here. Rule R-FCR-017-1. Check: Search for a vendor, select it, and verify the vendor appears in the participant list.
- **Product** (column): It identifies the required Product column for each BOQ line item. Affects: It controls each line item's product_uuid and requires a product value before publishing.. Leads to: stays here. Rule R-FCR-008-1. Check: Verify each line requires a product before the event can be published.
- **Quantity Requested** (column): It identifies the required Quantity Requested column for each BOQ line item. Affects: It controls each line item's requested quantity and requires a quantity value.. Leads to: stays here. Rule R-FCR-008-1. Check: Enter a quantity and verify it is retained for the line item.
- **Price** (column): It identifies the required Price column for each BOQ line item. Affects: It controls the required line-item price used for auction or bid calculations.. Leads to: stays here. Rule R-FCR-005-5. Check: Enter a price and verify it is retained and included in the line calculation.
- **GST Percentage** (column): It identifies the optional GST Percentage column. Affects: It controls the tax percentage used to calculate the post-GST amount when populated.. Leads to: stays here. Check: Enter a GST percentage and verify the calculated tax-inclusive amount changes.
- **Total Amount** (column): It identifies the required Total Amount column. Affects: It represents the line total derived from the line's quantity and price and is required for the event data.. Leads to: stays here. Rule R-FCR-008-1. Check: Change quantity or price and verify Total Amount recalculates.
- **Total Amount after GST** (column): It identifies the required Total Amount after GST column. Affects: It represents the tax-inclusive line total used in the event's pricing data.. Leads to: stays here. Rule R-FCR-008-1. Check: Change GST Percentage and verify Total Amount after GST recalculates.

## Test cases written from the boq-template-selected screen

- GEN-SCR-155: Publish is refused when no participants are added. Steps: Enter a project title. Click "Publish". Expected: Publishing stops. The message "Please add participants to proceed!" appears. [plan: full]
- GEN-SCR-156: Save as draft becomes available only for eligible projects. Steps: Open the project creation screen. Verify the state of "Save as draft". Repeat with draft project creation disabled or with a recurring stage. Expected: "Save as draft" is enabled only when all eligibility conditions are met. It is disabled when draft project creation is unavailable or the project is recurring. [plan: partial]
- GEN-SCR-157: Publishing without an end time is rejected. Steps: Click "Now - 02:09 am, 21st Oct ( 30 Mins )". Choose a custom duration. Leave the end time empty. Close the schedule popover. Click "Publish". Expected: Publishing fails with the message "Please add end time for the event". [plan: partial]
- GEN-SCR-158: Publish confirmation uses the Auction Team wording. Steps: Click "Publish". Inspect the confirmation modal. Expected: The modal title is "Send to Auction Team". The project title shown in the modal is truncated to 45 characters. The modal shows "Publish Event" and an OK action labeled "Send to Auction Team". [plan: partial]
- GEN-SCR-159: Locked product fields cannot be edited during RFQ-to-Auction conversion. Steps: Try to edit a cell under "Product". Try to edit a cell under "Quantity Requested". Try to replace the product or quantity value. Expected: The product and requested quantity cells are read-only. No product or quantity value can be changed from this screen. [plan: partial]
- GEN-SCR-160: Ask Clara opens the summary panel in the disabled-Clara configuration. Steps: Click "Ask Clara". Expected: The Clara summary panel renders and displays the project's existing summary. [plan: partial]
- GEN-SCR-251: Publish opens the event confirmation. Steps: Click "Publish". Inspect the confirmation dialog. Do not confirm the publish. Expected: A confirmation dialog appears with the title "Publish Event". The dialog shows an OK action labeled "Publish" and a cancel action labeled "Edit Schedule". Choosing "Edit Schedule" opens the schedule drawer. [plan: full]
- GEN-SCR-252: Changing the selected BOQ shows a reset warning. Steps: Click "New BOQ 2". Inspect the warning. Do not confirm the template change. Expected: A warning appears stating "Changing template will reset data. Are you sure?". The confirmation option is labeled "Yes". [plan: full]
- GEN-SCR-253: Save as draft is disabled on the initial screen. Steps: Inspect "Save as draft". Try to click "Save as draft". Expected: "Save as draft" is visibly disabled and cannot be activated. No draft-save action starts. [plan: full]
- GEN-SCR-254: Add Attachments opens the attachment interface. Steps: Click "Add Attachments". Expected: An attachment picker or attachment panel opens, allowing the tester to begin adding an attachment without leaving the BOQ creation screen. [plan: full]
- GEN-SCR-255: Rank on lot opens lot-ranking configuration. Steps: Click "Rank on lot". Inspect the configuration that opens. Expected: The lot-ranking auction configuration opens. It shows rank-based evaluation for the lot rather than product-level ranking. [plan: full]
- GEN-SCR-382: Upload Sheet opens the sheet upload flow. Steps: Click Upload Sheet. Expected: The sheet upload interface opens and allows the tester to choose a sheet for upload. [plan: full]
- GEN-SCR-383: Add New creates a line-item row with required columns. Steps: Click Add New. Expected: A new line-item row appears. Product, Quantity Requested, Price, Total Amount, and Total Amount after GST are present and marked required. [plan: partial]
