## Test cases written from the boq-template-selected screen

- GEN-SCR-155: Publish is refused when no participants are added. Steps: Enter a project title. Click "Publish". Expected: Publishing stops. The message "Please add participants to proceed!" appears. [plan: full]
- GEN-SCR-156: Save as draft becomes available only for eligible projects. Steps: Open the project creation screen. Verify the state of "Save as draft". Repeat with draft project creation disabled or with a recurring stage. Expected: "Save as draft" is enabled only when all eligibility conditions are met. It is disabled when draft project creation is unavailable or the project is recurring. [plan: partial]
- GEN-SCR-157: Publishing without an end time is rejected. Steps: Click "Now - 02:09 am, 21st Oct ( 30 Mins )". Choose a custom duration. Leave the end time empty. Close the schedule popover. Click "Publish". Expected: Publishing fails with the message "Please add end time for the event". [plan: full]
- GEN-SCR-158: Publish confirmation uses the Auction Team wording. Steps: Click "Publish". Inspect the confirmation modal. Expected: The modal title is "Send to Auction Team". The project title shown in the modal is truncated to 45 characters. The modal shows "Publish Event" and an OK action labeled "Send to Auction Team". [plan: partial]
- GEN-SCR-159: Locked product fields cannot be edited during RFQ-to-Auction conversion. Steps: Try to edit a cell under "Product". Try to edit a cell under "Quantity Requested". Try to replace the product or quantity value. Expected: The product and requested quantity cells are read-only. No product or quantity value can be changed from this screen. [plan: partial]
- GEN-SCR-160: Ask Clara opens the summary panel in the disabled-Clara configuration. Steps: Click "Ask Clara". Expected: The Clara summary panel renders and displays the project's existing summary. [plan: partial]
- GEN-SCR-251: Publish opens the event confirmation. Steps: Click "Publish". Inspect the confirmation dialog. Do not confirm the publish. Expected: A confirmation dialog appears with the title "Publish Event". The dialog shows an OK action labeled "Publish" and a cancel action labeled "Edit Schedule". Choosing "Edit Schedule" opens the schedule drawer. [plan: full]
- GEN-SCR-252: Changing the selected BOQ shows a reset warning. Steps: Click "New BOQ 2". Inspect the warning. Do not confirm the template change. Expected: A warning appears stating "Changing template will reset data. Are you sure?". The confirmation option is labeled "Yes". [plan: full]
- GEN-SCR-253: Save as draft is disabled on the initial screen. Steps: Inspect "Save as draft". Try to click "Save as draft". Expected: "Save as draft" is visibly disabled and cannot be activated. No draft-save action starts. [plan: full]
- GEN-SCR-254: Add Attachments opens the attachment interface. Steps: Click "Add Attachments". Expected: An attachment picker or attachment panel opens, allowing the tester to begin adding an attachment without leaving the BOQ creation screen. [plan: partial]
- GEN-SCR-255: Rank on lot opens lot-ranking configuration. Steps: Click "Rank on lot". Inspect the configuration that opens. Expected: The lot-ranking auction configuration opens. It shows rank-based evaluation for the lot rather than product-level ranking. [plan: full]
