## Test cases written from the create-participants screen

- GEN-SCR-105: Duration shows the configured preset values. Steps: Open Duration. Review the available duration choices. Choose a duration preset. Review the schedule summary. Expected: The menu contains the configured duration presets, or the defaults 30 mins, 1 hour, 4 hours, and 24 hours. The schedule summary reflects the selected duration. [plan: partial]
- GEN-SCR-106: Recurring event changes the Publish label. Steps: Turn on Mark as Recurring EventSet this event to repeat automaticall. Review the publish action label. Expected: The action label changes from "Publish" to "Save Recurring Event". [plan: full]
- GEN-SCR-107: Required line-item columns are marked. Steps: Review the column headers in the items grid. Compare the required markers on each header. Expected: Product, Product Variant, Quantity Requested, Delivery location, Price, Quantity Available, and Total Amount show required markers. GST does not show a required marker. [plan: partial]
- GEN-SCR-224: Custom duration without an end time is rejected on publish. Steps: Open Duration. Select Custom duration. Close the duration popover without entering an end time. Click Save Schedule. Click Publish. Expected: The schedule saves, but publishing is refused with "Please add end time for the event". [plan: full]
- GEN-SCR-225: Fixed-time scheduling enables the date field. Steps: Open Start now. Select Fixed time. Review Select date and Select time. Expected: Select date is enabled for input, and Select time is available for the fixed-time schedule. [plan: partial]
- GEN-SCR-226: Recurring scheduling is copied to every stage. Steps: Open the schedule for the current stage. Turn on Mark as Recurring EventSet this event to repeat automaticall. Configure the recurring schedule. Click Save Schedule. Open Technical Stage and review its schedule. Open RFQ and review its schedule. Expected: Both stages show the same recurring configuration after the schedule is saved. [plan: full]
- GEN-SCR-227: Required line-item columns are visibly marked. Steps: Review the headers Product, Product Variant, Quantity Requested, Delivery location, Price, Quantity Available, and Total Amount. Expected: Each listed header displays a required marker. GST does not display a required marker. [plan: partial]
- GEN-SCR-340: Publish confirmation shows stage schedule and vendor details. Steps: Click "Publish". Review the stage information in the confirmation modal. Do not confirm the publish action. Expected: The modal shows "Starts on:", "Ending at:" with the duration in parentheses, and "Vendors invited:" with the de-duplicated vendor count. The event is not published. [plan: partial]
- GEN-SCR-341: Custom duration without an end time is refused on publish. Steps: Open "Duration". Choose "Custom duration". Close the duration popover without entering an end time. Click "Save Schedule". Click "Publish". Expected: Saving the schedule completes, but publishing is refused with the message "Please add end time for the event". [plan: full]
