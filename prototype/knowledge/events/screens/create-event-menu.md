## What each control on create-event-menu does

- **Ask Clara** (button): Opens the Clara assistant. Affects: nothing. Leads to: Clara assistant drawer. Check: Click Ask Clara and verify that the assistant drawer opens.
- **Create Event M** (button): Clicking Create Event opens the event-creation menu. Affects: nothing until a creation mode is selected.. Leads to: Create event menu.. Rule R-FLA-009-1. Check: Click Create Event and verify that the creation options are displayed.
- **Live 8641** (tab): Clicking Live selects the live-events list. Affects: the active tab becomes live and the live event list is loaded.. Leads to: Live events list on the orders screen.. Rule R-FLA-002-1. Check: Click Live and verify that it is selected and live events are shown.
- **History 2036** (tab): Clicking History selects the history list. Affects: the active tab becomes history and historical events are loaded.. Leads to: History events list on the orders screen.. Rule R-FLA-003-3. Check: Click History and verify that it is selected and historical events are shown.
- **Drafts 185** (tab): Clicking Drafts selects the drafts list. Affects: the active tab becomes drafts and draft events are loaded.. Leads to: Drafts list on the orders screen.. Rule R-FLA-003-3. Check: Click Drafts and verify that it is selected and draft events are shown.
- **Recurring** (tab): Clicking Recurring selects the recurring-events list. Affects: the active tab becomes recurring and scheduled recurring events are loaded.. Leads to: Recurring events list on the orders screen.. Rule R-FLA-003-3. Check: Click Recurring and verify that it is selected and recurring events are shown.
- **Single Stage Source through RFP / RFQ / Auction** (menuitem): Clicking Single Stage Source through RFP / RFQ / Auction opens single-stage event creation. Affects: the creation flow is marked as single-stage.. Leads to: Quick-create screen with the single-stage flag.. Rule R-FLA-009-1. Check: Select the single-stage option and verify that the quick-create screen opens for one stage.
- **eRFX Project Manage sourcing via a project approach** (menuitem): Clicking eRFX Project opens the product-selection flow for a multi-stage project. Affects: the buyer can add project line items before an event group is created.. Leads to: Add Line Items modal or drawer.. Rule R-FLA-009-1. Check: Select eRFX Project and verify that the Add Line Items interface opens.
- **BOQ based RFX Project Source BOQ via a project approach** (menuitem): Clicking BOQ based RFX Project opens the BOQ project product-selection flow. Affects: the buyer can configure a BOQ-based project before its event group is created.. Leads to: Add Line Items modal or drawer.. Rule R-FLA-009-1. Check: Select BOQ based RFX Project and verify that the BOQ line-item interface opens.
- **Search Title** (field): Entering text in Search Title filters the event list by title. Affects: the list filter state and the events returned or displayed on the current tab.. Leads to: Stays here.. Check: Enter a distinctive title and verify that unrelated events are removed from the list.
- **Starting from** (field, disabled): Cannot be edited because it is disabled. Affects: nothing. Leads to: stays here. Check: Try to enter a start date and verify that the field remains disabled and unchanged.
- **Ending at** (field, disabled): Cannot be edited because it is disabled. Affects: nothing. Leads to: stays here. Check: Try to enter an end date and verify that the field remains disabled and unchanged.

Expected: Starting from and Ending at are disabled. They do not accept focus, typing, or date changes, and no date filter is applied. [plan: partial]
