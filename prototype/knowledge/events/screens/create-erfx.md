## What each control on create-erfx does

- **Ask Clara** (button): Opens the Clara assistance panel for generating or reviewing RFP content. Affects: May create or populate AI-generated RFP questions, but requires line items.. Leads to: Clara assistance panel. Rule R-FCR-042-4. Check: Click Ask Clara and verify that the Clara panel opens or that the missing-line-items requirement is shown.
- **Add Attachments** (button): Opens the attachment control so the buyer can add files. Affects: Adds attachments to the project data for use in the event.. Leads to: Attachments drawer or dialog. Rule R-FCR-008-1. Check: Click Add Attachments and verify that an attachment picker opens.
- **Add T&Cs** (button): Opens the terms-and-conditions control for entering or attaching T&Cs. Affects: Updates the project's terms_and_conditions data.. Leads to: Terms and Conditions drawer or dialog. Rule R-FCR-008-3. Check: Click Add T&Cs and verify that the T&C editor opens.
- **Items 0** (button): Opens the line-item manager. Affects: Allows the buyer to add, edit, or delete the event's line items, which are required before proceeding.. Leads to: Manage line items drawer or dialog. Rule R-FCR-014-3. Check: Click Items 0 and verify that the manage line items interface opens and shows zero items.
- **Save as draft** (button, disabled): Remains unavailable because the event has no line items and no selected template. Affects: Nothing because no save action can be performed.. Leads to: stays here. Rule R-FCR-016-2. Check: Verify the button is disabled and its tooltip explains that a template and line items are required.
- **Publish** (button): Validates the project and starts publishing the event. Affects: Changes the project and its stages from draft toward publication, subject to validation and participant requirements.. Leads to: Publish confirmation dialog or the resulting event state. Rule R-FCR-020-2. Check: Add the required title, template, line item, and participant, click Publish, and verify the publish confirmation appears.
- **Rank on lot** (button): Sets or displays the auction's lot-ranking configuration. Affects: Changes whether auction closing and ranking are handled at lot level.. Leads to: stays here. Rule R-FCR-009-1. Check: Toggle Rank on lot and verify that the lot-based auction setting changes.
- **Select Templates** (button): Opens the template picker for selecting a commercial event template. Affects: Sets the stage template and unlocks template-dependent configuration and actions.. Leads to: Template selection drawer. Rule R-FCR-026-4. Check: Click Select Templates and verify that available templates are listed for selection.
- **Participants** (button): Opens the participant management control. Affects: Adds or removes vendors and updates the project's participant or audience records.. Leads to: Participants drawer. Rule R-FCR-017-1. Check: Click Participants and verify that the participant list and vendor-management actions appear.
- **Savings** (button, disabled): The disabled button cannot open or edit savings settings. Affects: nothing because savings cannot currently be changed.. Leads to: stays here. Rule R-FCR-024-2. Check: Verify that Savings is disabled until a template and at least one product are present.
- **Terms & Conditions** (button, disabled): The disabled button cannot open or edit terms and conditions settings. Affects: nothing because the control is unavailable.. Leads to: stays here. Rule R-FCR-024-2. Check: Verify that Terms & Conditions is disabled while the required template and product prerequisites are missing.
- **Now - 04:32 pm, 21st Oct ( 30 Mins )** (button, disabled): Cannot be opened because the event schedule control is disabled. Affects: Nothing because the event timing cannot be changed from this state.. Leads to: stays here. Rule R-FCR-016-2. Check: Verify that the schedule button is disabled and does not open a scheduling control.
- **Auction** (tab): Keeps the event in Auction mode. Affects: Sets or retains the event mode as auction and exposes auction-specific configuration.. Leads to: stays here. Rule R-FCR-029-6. Check: Verify that Auction remains selected and the auction configuration is displayed.
- **Events** (link): Navigates to the Events page. Affects: Nothing in the current event data.. Leads to: Events screen. Check: Click Events and verify that the Events listing opens.
- **Enter the title of the project** (field): Accepts and updates the project title. Affects: Changes the title sent with the project save or publish payload; an empty title blocks publishing.. Leads to: stays here. Rule R-FCR-013-1. Check: Enter a title, leave the field, and verify that the title remains populated for save or publish.
- **Search vendors you want to add** (select, disabled): Cannot search for or add vendors because the vendor selector is disabled. Affects: Nothing because no participant or audience record can be changed through this field.. Leads to: stays here. Rule R-FCR-016-2. Check: Verify that the selector is disabled and cannot open vendor search results.
