# How to Create RFQ and Auction Templates

Source: Notion Knowledge Base — How to Create RFQ and Auction Templates (https://app.notion.com/p/60e92226c8b2831fa8b7017e26ec60fe) · last edited 2026-04-17
Section: Introduction

On the Procol platform, you can create RFQ and Auction templates for your sourcing events. Templates help buyers predefine formats, terms, awarding rules, and data fields so that events can be launched quickly without repeatedly configuring the same settings. These templates can also include both line-item-specific fields (quote sheet) and overall event fields (global sheet).

## Step-by-Step Process — How to Create RFQ and Auction Templates

[image: Templates page]

1. Go to the **homepage** and navigate to the **Manage** tab in the left-side navigation panel.
   [image: Manage tab in the left navigation]
2. Hover over **Manage** to view options such as Product Categories, Teams, Locations, Users, Templates, and Approval Workflows.
   [image: Manage hover menu]
3. Click on **Templates**.
   [image]
4. On the Templates page, click on **Create Template**.
5. Hover over the **Create Template** button and select **RFQ/Auction**.
   [image: Create Template menu with RFQ/Auction]
6. You are taken to the **Template Creation page**. Here, enter the **Template Title** and verify that the category is **RFQ/Auction**.
   [image: Template Creation page, title and category]
7. (Optional) Convert the template into a **BOQ template** by enabling the BOQ option.
   [image: BOQ option]
8. Click on the "**Add TnC**" button to add or edit **Terms & Conditions** for the template.
   [image: Add TnC]
9. Click on **Ranking Criteria** to open the **Awarding Criteria** module. Here, you can:
   - Select awarding criteria on lot or line item
   - Select **Template Type** (Buy or Sell) from the dropdown
   [image: Awarding Criteria module]
10. The template is divided into two main sections:
    - **Quote Sheet**: Contains line-item-specific fields (Quote sheets are duplicated for each line item)
      [image: Quote Sheet]
    - **Global Sheet**: Contains fields applicable across the entire event (only one global sheet will be )
      [image: Global Sheet]
11. Use the 6-dots **drag-and-drop** option to rearrange the position of fields within a sheet.
    [image: 6-dots drag handle]
12. Switch between **Horizontal or Vertical view** using the view toggle button.
    [image: view toggle]
13. To add a new column, click on the **Add** button.
    [image: Add button]
14. Select the type of column you want to add. Options include:
    - Text
    - Creator Attachment
    - Participant Attachment
    - Date
    - Price
    - Amount
    - Number
    - Percentage
    - Dropdown
    - Formula
    [image: column type list]
15. Configure the column based on its type. Examples:
    - **Text column**: Enter column name, key attribute (filled automatically when name is filled), set mandatory/hidden options.
    - **Date column**: Enter column name, select date format, set default value.
      1. Select Date format
      2. Select default value (optional)
    - **Price/Amount/Number**: Enter column name, key attribute (filled automatically when name is filled), prefix, suffix, and precision.
    - **Percentage**: Enter column name and key attribute (filled automatically when name is filled)
    - **Dropdown**: Enter column name, key attribute (filled automatically when name is filled), and dropdown values (either choose from an existing list or create a new one).
      1. Existing dropdown
      2. Existing Dropdown
         a. Type Name for List
         b. Click on Add option
         c. Type in the options
         d. Click on X to remove an option
    - **Formula**: Use curly brackets `{}` for field names with operators to define calculations.
    [image: column configuration screens for each type]
16. Configure column toggles as required:
    - **Mandatory** → Field must be filled in.
    - **Hidden** → Field is inactive in the template.
    - **Hide from Participant** → Field not visible to vendors.
    - **Buyer Editable** → Buyer can edit participant fields.
    - **Creator/Participant Field** → Defines who must fill in the field.
    [image: column toggles]
17. Set precision for number-based fields (0–4 decimal positions).
    [image: precision setting]
18. You can also **Duplicate** or **Delete** a column by clicking on the three dots next to "Column settings"
    [image: three-dot menu with Duplicate / Delete]
19. Once configuration is complete, the template can be published by clicking on the blue **"Publish"** button
    [image: Publish button]

> **Note.** The Template is now published and can be used for future RFQs and Auctions
> [image: published template]
