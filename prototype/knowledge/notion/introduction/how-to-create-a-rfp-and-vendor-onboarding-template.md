# How to Create a RFP and Vendor Onboarding Template

Source: Notion Knowledge Base — How to Create a RFP and Vendor Onboarding Template (https://app.notion.com/p/a2a92226c8b282478ec181e10435d1ed) · last edited 2026-04-20
Section: Introduction

In Procol, you can set up RFP (Request for Proposal) and Vendor Onboarding templates, similar to RFQ and Auction templates. These templates help standardize how vendor information is collected and how proposals are structured, ensuring consistency across sourcing and onboarding processes. Templates can be configured in either **form view** or **table view**, with flexible field types for capturing vendor responses.

## Step-by-Step Process — How to Create a RFP and Vendor Onboarding Template

1. Go to the **homepage** and navigate to the **Manage** tab in the left-side navigation panel.
   [image: Manage tab]
2. Hover over **Manage** to view options such as Product Categories, Teams, Locations, Users, Templates, and Approval Workflows.
   [image: Manage hover menu]
3. Click on **Templates**.
4. On the Templates page, click on **Create Template**.
5. Hover over the **Create Template** button and select **RFP**
   [image: Create Template menu with RFP]
6. You are taken to the **Template Creation page**. Here, enter the **Template Title** and verify that the category is **RFQ/Auction**.
   [image: Template Creation page]
7. (Optional) Convert the template into a **Vendor Onboarding template** by enabling the **Vendor Onboarding** option.
   [image: Vendor Onboarding option]
8. Click on the "**Add TnC**" button to add or edit **Terms & Conditions** for the template.
   [image: Add TnC]
9. Add **Evaluators** by searching for their names and selecting them.
   [image: Evaluators search]
10. Go to the **Basic Details** section.
    - Click **Edit icon** to rename the section. (Click on Save when you are done)
    - Click **Delete** icon to remove the section (a confirmation pop-up appears).
    - Click **Add New Section** to create a new one.
11. In Basic Details, toggle between **Form View** and **Table View**.
    - **Form View:** Displays questions as a form.
    - **Table View:** Displays three columns: Question, Description, Vendor Response.
12. In **Table View**, next to each Vendor Response, click **Edit icon next to** the field type to change it.
    Available field types:
    - Short Text
    - Long Text
    - Single Select
    - Radio
    - Number
    - Attachment
    - Date
    [image: Table View field-type editor]
13. You can also mark fields as **Required** or delete a question.
    [image: Required toggle and delete in Table View]
14. To build your RFP or Vendor Onboarding form in **Form View**, click **Add New Question**.
15. In the pop-up window, enter:
    - Question
    - Description
    - Field Type
    - Required toggle (Yes/No)
    [image: Add New Question pop-up]
16. Available field types in Form View:
    - **Short Text** – Single-line response
    - **Long Text** – Multi-line response
    - **Single Select** – Dropdown with pre-defined options
    - **Radio** – Single-choice option (similar to Single Select)
    - **Number** – Numeric field (letters not allowed)
    - **Attachment** – Vendors can upload files (images, docs, etc.)
    - **Date** – Calendar picker
17. For **Single Select** and **Radio** fields:
    - Click **Add Option** to type in response options.
    - Press **Enter** to add multiple options.
    - Use **Delete** to remove a specific option, or **Delete All** to clear all options.
    [image: option editor]
18. Once options are configured, click **Add** (blue button) to save the question.
19. To edit an existing question, click the **Edit** icon.
20. To delete a question, click the **Delete** icon. A confirmation pop-up will appear.
21. Use the **Required toggle** on each question directly to mark it mandatory without reopening the edit window.
22. You can add a New Section by Clicking on the New Section Button which opens up a pop up
23. Type in the section name and click on "Add" when you're done.
24. There is an option to Bulk Upload Questions via Excel
25. Click on "**Download template**" to download a template sheet to fill in the line item details.
26. You can open the sheet that has been downloaded using google sheets or Microsoft Excel.
27. Upload the filled and downloaded file in the modal.
28. Click on OK
29. When you're template is done you can click on "Create"
    [image: Create button]

> **Note.** You're RFP Template is now created
