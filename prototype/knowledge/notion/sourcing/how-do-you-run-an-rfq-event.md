# How do you run an RFQ Event?

Source: Notion Knowledge Base — How do you run an RFQ Event? (https://app.notion.com/p/b4592226c8b2831ca5c4012f1e9b5c40) · last edited 2026-04-12
Section: Sourcing › RFQ

**Persona:** Buyer

This guide explains how a buyer can run and manage a Request for Quotation (RFQ) event on the platform. You should read this after you have created and published your sourcing or stand-alone RFQ event.

## Accessing the RFQ Event — Run an RFQ Event

1. Navigate to the **Events** tab on the left-hand menu.
2. Find and click on the card for the event that has been published.
3. You'll be directed to the RFQ Responses tab where vendor quotes can be monitored and managed.

## Comparing Vendor Quotes — Run an RFQ Event

1. Scroll through the various line items to compare prices submitted by different vendors.
2. The system will automatically highlight the **L1 (Lowest)** price in green for each line item.
3. A percentage icon next to the bid shows the savings compared to the previous bid submitted by that vendor.

## Managing Individual Quotes — Run an RFQ Event

1. Click on the **three-dot menu** next to any vendor's name in their quote to see more options.
2. Select **Reject Quote** to remove it from the comparison view and the Quote Comparison Sheet (QCS). Choose whether the Seller is Allowed to bid again or not by checking or unchecking the box.
3. Select **Edit Quote** to update specific global fields such as taxes or delivery terms that may not have been provided by the vendor or were hidden during bid submission.

## Reviewing Previous Vendor Bids — Run an RFQ Event

1. Hover over "Current bid" value to view the vendor's past bids. Select which bid version you would like to jump to.
2. Use the arrow buttons next to the bid value to cycle through previous revisions submitted by the vendor or go back to the current bid.

## Sending Counter Offers — Run an RFQ Event

1. Locate the vendor name in the comparison view.
2. Click the **Counter Offer** button displayed under the vendor name.
3. You will be taken to the counter offer interface to configure and send your revised expectations to the vendor.

> **Note.** To understand the full flow for counter offers, see the related counter-offer Knowledge Base article.

## Using the Actions Button — Run an RFQ Event

1. Click the **Actions** button to access advanced controls.
2. Select **Show Best Prices** to show Suppliers the exact best price for each line item. It also adds an extra row for each line item that displays the lowest bid across vendors in the QCS.
3. Select **Enable English Auction** to convert the RFQ into an English Auction event. For more details, see the related Knowledge Base article.
4. Select **Enable View-Only Mode** to restrict users from sending counter offers, editing quotes, or placing surrogate bids. You can disable this mode by clicking on the same action again.

## Sending Bulk Counter Offers — Run an RFQ Event

1. Click on Settings and find "Send Bulk Counter Offers".
2. Decide the counter offer you want to send to all vendors and click on Send.

> **Note.** For a detailed walkthrough, refer to the "How to Send Bulk Counter Offers" guide.

## Requesting for Best Offer — Run an RFQ Event

Want the final and **Best offer** from your Vendors? Click on "Request for Best Offer" under the "Settings" dropdown.

> **Note.** Once Evaluation time has started you can request for Best Offer. Refer to the "How do you use Request for Best Offer" knowledge base entry if needed.

## Awarding the RFQ — Run an RFQ Event

> **Note.** Once you've completed your evaluation and sent counter offers, navigate to the **MQCS** tab. Refer to the "Awarding Process" knowledge base entry if needed.

## Converting the RFQ to an Auction — Run an RFQ Event

If you'd like vendors to compete further to reduce prices, click on the **Convert to Auction** button.

> **Note.** Follow the guided steps to switch the event into an auction mode. Refer to the "How to Convert RFQ to Auction" knowledge base page for more details.
