# How to Send Bulk Counter Offers?

## Sending Bulk Counter Offers — Send Bulk Counter Offers

1. Click on Settings and find "Send Bulk Counter Offers"
   [image: Settings menu with "Send Bulk Counter Offers"]
2. Decide the counter offer you want to send to all vendors and click on Send
   [image: bulk counter offer dialog]
3. Select the field you want to apply a counter offer on.
   *Common fields include Price and Quantity. You may also send counter offers on global fields.*
   [image: field selection]
4. Input the new value you want to propose.
   *The dialog will show both the original vendor value and the counter offer value for easy comparison.*
   [image: original vendor value vs counter offer value]

> **Note.** You can also send Counter Offers on Global Fields (fields that are not specific to any particular line item). [image: global fields]

5. (Optional) Add a note to the vendor explaining the counter offer.
   *This is helpful for negotiation context but not mandatory.*
   [image: note to vendor field]
6. Click **"Send Counter Offer"** to confirm.
   *You will receive a tooltip notification that the counter offer was sent successfully.*
   [image: "Send Counter Offer" button]
   [image: counter offer sent confirmation]
7. After sending, a tag saying **"Counter Offer Requested"** appears above all the vendor's name in the QCS.
   *You will also see a "Revoke Counter Offer" option.*
   *Changed values are highlighted, showing original vs counter offer values.*
   [image: "Counter Offer Requested" tag in the QCS]
