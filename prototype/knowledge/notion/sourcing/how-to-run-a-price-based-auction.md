# How to Run a Price - Based Auction

Source: Notion Knowledge Base — How to Run a Price - Based Auction (https://app.notion.com/p/1fe92226c8b28207b67a01f1e19a21bf) · last edited 2026-04-12
Section: Sourcing › Auction

A price - based auction is an auction strategy that buyers can configure for their events when they want precise competitive bidding from their suppliers.

## Steps to Enable Serial Bidding — Run a Price-Based Auction

(The heading is as written in Notion; the steps below set up a Price Based auction.)

1. Create a new event in Procol.
   [image: create new event]
2. In the **Event Type** dropdown, select **Auction**.
   [image: Event Type dropdown]
   [image: Auction selected]
3. Select The "Price Based" Auction Strategy
   [image: Price Based strategy]
4. Click on Save and Publish the Event
   [image: Save and Publish]
5. Once the Bids are placed you will be able to see the best price among all bids
   [image: buyer view with best price]
6. The Vendors will also be able to see the Best Price , so they know which price to beat!
   [image: vendor view with Best Price]
7. If you want to see Rank as well in a price based Auction, you can click on Actions
   [image: Actions]
8. Click the Checkbox next to show Rank to toggle it on.
   [image: show Rank checkbox]
   [image: show Rank enabled]
9. You can now see the Ranks as well next to the Best Price.
   [image: ranks next to Best Price]
