# How to Edit Currencies in my Event

Source: Notion Knowledge Base — How to Edit Currencies in my Event (https://app.notion.com/p/94e92226c8b2834494cf81dcb83af5d2) · last edited 2026-04-21
Section: Sourcing › Creating Events

This guide explains how to edit your currencies when creating a sourcing event in Procol. You can define whether to have multiple currencies or change your base currency in which your vendors are bidding in. This would allow vendors from other countries to easily place bids without doing any manual calculations. Meanwhile you would be able to compare bids in the default currency of your choice! You can also manually add conversion factors to maintain transparency with Vendors!

## Persona — Edit Currencies in my Event

Buyers, Procurement managers

## Step-by-step process — Edit Currencies in my Event

[image: event creation screen]

1. While creating a new event, go to the bottom-left of the page and click on the "Edit Currencies" option.
2. A pop up panel will open showing currency configuration settings.
3. Choose your multi currency mode:
   - Select **Multiple Currency** if you want to let your default currency stay as is but allow Vendors to bid in multiple currencies as well as define the conversion rates. These bids will convert to your default currency and populate your RFQ/Auction QCS.
   - Select **Base Currency** if you want to change the default or base currency of that event.

## To Set Up Multi Currency — Edit Currencies in my Event

1. Select **Multi Currency**.
2. Click on the **Checkbox** to tick it, next to the currency you would like to add to your event.
3. Add a **conversion factor** in the input box next to the currency.
4. Once you're done you can click on OK.

## To Set Up Base Currency — Edit Currencies in my Event

1. Select **Base Currency**.
2. Select the new Base Currency from the dropdown list, by clicking on **"Select Base Currency"**.
3. Add a **conversion factor** in the input box below the dropdown.
4. Once you're done you can click on OK.
