# How to set Savings references in an Event?

Source: Notion Knowledge Base — How to set Savings references in an Event? (https://app.notion.com/p/6ec92226c8b283a0b50c01fed41a8ec2) · last edited 2026-04-21
Section: Sourcing › Creating Events

This guide explains how to set up savings calculation preferences when creating an event in Procol. You can define whether savings should be calculated based on the gross total for the event or at the line item level. You can also enter reference values such as budget, historical price, or add custom strategies. This helps in tracking cost savings accurately during the evaluation and awarding process.

## Persona — Savings references in an Event

Buyers, Procurement managers

## Step-by-step process — Savings references in an Event

[image: event creation screen]

1. While creating a new event, go to the bottom-left corner of the page and click on the "Savings" option.
2. A side panel will open showing saving calculation settings.
3. Choose how you want to calculate savings:
   - Select **Gross Total** if you want to track savings for the full event.
   - Select **Line Item** if you want to track savings for each line item individually.
4. There are three types of default Savings References.
5. If you selected **Gross Total**, enter a single reference value for one or more of the default savings categories: Budget, Historical Price, and Existing Proposal.
6. If you selected **Line Item**, choose whether you want to calculate savings based on:
   - **Price** (savings per unit, excluding quantity) or
   - **Total Amount** (savings calculated on price multiplied by quantity)

> **Note.** Price is Quantity independent while Total Amount will consider quantity also.

7. To create a custom savings strategy, click on "Add a Custom Reference".
8. Type the name for the custom strategy (e.g. Best Price) and click "Save".
9. Once added, select the column you want to calculate the savings on for this custom strategy.
10. To save time on large events, use the "Paste from CSV" feature to bulk enter reference values from Excel:
    1. Copy Values from Excel.
    2. Go to the saving panel.
    3. Click on "Paste from CSV".
    4. The Values are pasted in the cells automatically.
