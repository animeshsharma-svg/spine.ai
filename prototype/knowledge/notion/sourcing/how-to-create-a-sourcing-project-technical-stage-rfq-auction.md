# How to create a Sourcing Project (Technical Stage, RFQ, Auction)?

Source: Notion Knowledge Base — How to create a Sourcing Project (Technical Stage, RFQ, Auction)? (https://app.notion.com/p/0da92226c8b283928ce601a58da61765) · last edited 2026-04-12
Section: Sourcing › Creating Events

A Sourcing Project is a series of events created at the same time under the same project ID. These are a combination of a Technical Stage (RFP) and a RFQ (Request for Quotation) or Reverse Auction. These events are interlinked and connected.

> **Note.** To understand how to create a standalone event, see the article "How to create a Single Stage Event (RFP, RFQ, Auction)?".

## Who Is This For? — Sourcing Project

Buyers, Procurement Managers

## Steps to Create a Sourcing Project — Sourcing Project

1. Navigate to the **Events** page from the left navigation panel.
   [image: the Events screen]
2. Click on the "+ **New Event**" button.
3. In the panel that opens, choose **"eRFX Project"**.
4. In the side drawer that opens, you can search and add Line Items via the search bar on top.
5. **Quantities are editable** directly within the cart. Click on the quantity box and type in a new value.
6. You can change the UOM of the Qty by clicking on the small dropdown arrow near the UOM, and selecting the UOM you need from the dropdown. You can search through this dropdown as well.

> **Note.** You can **remove items** from the cart by clicking the **trash icon** next to each line.

7. Click the blue **"Create Project"** button on the bottom right to go ahead with processing these Line items. (It shows the number of how many items have been selected.)
8. Here, you are given the option to select which events you want to create as a part of your Sourcing Project. After selecting the type of events you need, you can click on **"Create Project"** again to start setting up your Events.

> **Note.** It's important to note that you cannot create an RFQ and Auction together. You can choose only one of the 2. This is because if you create an RFQ, you can separately convert that RFQ to an Auction. You can only have 2 stages at max during creation. To learn how to do that see "How do I convert an RFQ to an Auction".

> **Note.** You are taken to the project creation screen. [image: project creation screen]

You can see that a Project has been created with the stages (events) you have selected. A Technical Stage and an RFQ have been added.

9. Click on Select Template.
10. Choose a predefined **template** based on your use case.

> **Note.** Want to understand how to create templates? See the related Knowledge Base article.

Here you can see that the products and quantities are prefilled after selecting the template.

11. Click on the cells beneath Mandatory fields like Delivery Location to fill them in.

> **Note.** Different fields have different input types, like numbers, dropdowns, free text etc.

> **Note.** Shaded out fields that can't be filled in are for the Vendor to fill. Buyer's cannot fill in these fields.

12. Click on Technical Stage to review it as well.
13. Click on Select Template to apply an RFP Template for all the Line Items via Bulk Action.

> **Note.** You can see that for all line items the same template has been applied.

14. Click on select template under the "Vendor Assessment" Section.
15. Click on "+ Add Evaluator" under the first line item.
16. Search the user you want to assign as the technical evaluator. Repeat the same action for all the line items without fail.

> **Note.** Technical Evaluators are users who will assess the quality of the goods provided by a vendor basis the responses of the vendor in this stage. He can assign ranks (T1, T2, T3) or (TA - Technically Accepted or TNA - Technically Not Accepted).

17. Scroll to the bottom of the RFQ Page. The Procol platform suggests Vendors mapped to the products added by you in the above template. Click on the blue "Invite Vendors" shown in the green tip to automatically add them as participants.

> **Note.** Disclaimer: The Suggestion does not appear when you're on the Technical stage tab, only on RFQ and Auction tabs.

> **Note.** **Participants added are on a project-level and will be common for all stages.**

18. You can search, filter, or add vendors manually as well by clicking on Participants. The below screen shows up. [image: Participants screen]
19. Click on the Blue "Publish Event" button, at the top right of the screen.
20. In the Pop-up screen, review all the Event details. If everything seems in order, you can click on the blue "Publish" button. This will send an email notification to all added participants, inviting them to participate in the event that is now Live.
    *Alternatively, you can press "Edit Schedule" to schedule the event for later.*

> **Note.** **You Have Successfully Published your Event !!** [image: published event confirmation]

## Best Practices and Helpful Tips — Sourcing Project

> **Note.** Procol auto-generates the event title using product and location names, but you can edit this as needed.

> **Note.** The crossed out eye icon next to technical stage is a symbol used to indicate that this stage has not been reviewed by the user yet.

## Process Technical stage on Lot / Vendor Level — Sourcing Project

1. Click on Technical stage under Event Type. You can switch to Vendor wise evaluation to evaluate all line items by one person.
2. You can now add the Evaluator in the Vendor Assessment section rather than the line items section.

## Project-Level Actions — Sourcing Project

[image: project-level action buttons]

1. Add Project Level Attachments.
2. Add Project Level T&Cs — different from Event Specific T&Cs but follows the same method. (Learn more: "How to add Terms and Conditions for my Vendors in my Events?")
3. Manage Items — when you click on this, you open your cart functionality.

## Event / Stage-Level Specific Actions — Sourcing Project

[image: bottom-left stage options]

- **Click on Terms & Conditions** to add pre-saved or custom T&C that will be shown to the participating Vendors. (Learn more: "How to add Terms and Conditions for my Vendors in my Events?")
- **Click on Savings** to configure savings references. (Learn more: "How to set Savings references in an Event?")
- **Click on Edit Currencies** to edit the base or have multiple currencies. (Learn more: "How to Edit Currencies in my Event")
- **Click on Schedule** to schedule the event for a later date and time or to change the duration of the event. (Learn more: "How do I Schedule Events and change Event Duration?")

[image: template toolbar]

- **Click on "+ Add Columns"** to add custom Columns to the template for this event specifically. (Learn more: "How do I add additional columns to a Template?")
- **Click on "Upload Sheet"** to fill in the template details via uploading an Excel sheet. (Learn more: "How do I fill my tempate by uploading an Excel Sheet?")

> **Note.** This Guide uses a Technical Stage and RFQ. To understand how to set up an Auction, see the related Knowledge Base article.
