# How to set up an RFQ (Request for Quotation)?

Source: Notion Knowledge Base — How to set up an RFQ (Request for Quotation)? (https://app.notion.com/p/0a792226c8b282b6a09f81f9b8bf4dec) · last edited 2026-04-12
Section: Sourcing › RFQ

An RFQ (Request for Quotation) is a type of event where you can receive bids/quotations from multiple vendors/suppliers for the requested line items without the competitiveness of an Auction.

> **Note.** You will need to be on the event setup screen. By default, the **Event Type** is set to **Rank on Line**, a type of Reverse Auction. If not, see "How to create a Single Stage Event (RFP, RFQ, Auction)?".

## Steps to set up an RFQ — Set up an RFQ

1. Click on the **Rank on Line** badge to choose your **Event Type**. This opens a side drawer with 3 options:
   - **RFP (Request for Proposal)**
   - **RFQ (Request for Quotation)**
   - **Reverse Auction**

   Choose **RFQ (Request for Quotation)**.

   There is just one configuration to set while starting an RFQ.

   **Choose how you will award (to the vendors) in the event:**
   - "I may partially award the event to multiple vendors" - This runs the RFQ at a line item level.
   - "I'll award the entire lot to a single vendor" - This runs the RFQ at a Lot Level.
2. Click on Select Template.
3. Choose a predefined **template** based on your use case.

> **Note.** Want to understand how to create templates? See the related Knowledge Base article.

4. Add **products/items** for which you're seeking bids by clicking on the cell beneath the "Products" column and selecting from the dropdown. You can also type in the cell to narrow your search.
   - You can add more products in each subsequent row. (A new row will automatically be added each time)
   - There is a limit of up to 65 line items for this.
5. Fill in all **mandatory fields** in the template table. Quantities are free text. However, some fields, such as location, will be dropdowns similar to those for products (e.g., quantity, location, etc.).

> **Note.** Shaded out fields that can't be filled in are for the Vendor to fill. Buyer's cannot fill in these fields.

6. The Procol platform suggests Vendors mapped to the products added by you in the above template. Click on the blue "Invite Vendors" shown in the green tip to automatically add them as participants.
7. You can search, filter, or add vendors manually as well by clicking on Participants. The below screen shows up. [image: Participants screen]

> **Note.** Procol auto-generates the event title using product and location names, but you can edit this as needed.

8. Click on the Blue "Publish Event" button.
9. In the Pop-up screen, review all the Event details. If everything seems in order, you can click on the blue "Publish" button. This will send an email notification to all added participants, inviting them to participate in the event that is now Live.
   *Alternatively, you can press "Edit Schedule" to schedule the event for later.*

> **Note.** **You Have Successfully Published your RFQ Event !!**

> **Note.** Next, you may want to check out "How do you run an RFQ Event?".
