# How to run a Technical Stage Event?

Source: Notion Knowledge Base — How to run a Technical Stage Event? (https://app.notion.com/p/84c92226c8b28359ba4501eb60a2619b) · last edited 2026-04-12
Section: Sourcing › RFP / Technical Stage

The Technical Stage is the phase where vendors submit **product specifications**, **certifications**, and other technical details for your evaluation. This stage ensures that only technically compliant vendors move forward to the commercial evaluation.

## Who Is This For? — Run a Technical Stage Event

Buyers, Technical Evaluators

## Steps — Run a Technical Stage Event

> **Note.** This is the screen you see after publishing your RFX Event.

[image: screen after publishing the RFX event]

1. Navigate to the Technical Stage Tab
2. Wait for the Vendors to place their bids
   [image: Technical Stage tab]
   [image: waiting for vendor bids]

> **Note.** When the Vendors place their bids the Screen now looks like this

[image: Technical Stage with vendor bids]

3. Once all the vendors have submitted their bids, you can click on the blue **"Send to Evaluation"** button
   This sends a notification and gives access to the technical evaluator to make sure that he evaluates and assigns technical ranks to all of the line items.
   [image: Send to Evaluation button]

> **Note.** This triggers the start of the Evaluation time, which can be increased by the buyer, if the technical evaluator needs more time.

[image: Evaluation time]

> **Note.** Want to know how a Technical Evaluator, evaluates the line items, go to → (link to another KB page; the linked block could not be read from Notion)

> **Note.** Once the Evaluator Submits his Technical Rankings and the necessary approvals are provided, then only will the buyer will be able to see the technical evaluations.
> [image: technical evaluations visible to buyer]
