# How to create Serial Bidding events

Source: Notion Knowledge Base — How to create Serial Bidding events (https://app.notion.com/p/37a92226c8b28341bef7012f3622efc7) · last edited 2026-04-12
Section: Sourcing › Auction

Serial Bidding is used when each line item in an auction needs to be conducted separately, with its own submission duration, instead of all line items being open at the same time. This ensures that vendors can only place bids on one item at a time, creating a more controlled and focused bidding process.

## Steps to Enable Serial Bidding — Create Serial Bidding events

1. Create a new event in Procol.
   [image: create new event]
2. In the **Event Type** dropdown, select **Auction**.
   [image: Event Type dropdown]
   [image: Auction selected]
3. Enable the **Serial Bidding** option by clicking the toggle checkbox.
   [image: Serial Bidding toggle]
4. Enter the **duration** for each Line Item.
   [image: duration per line item]
5. The system will automatically calculate the **total submission time** based on the number of line items.
6. Add the required **Line Items** to the event.
   [image: line items]
7. Publish the event.
   [image: publish]

## Vendor Experience — Create Serial Bidding events

Buyers see the auction interface similar to a normal auction, but it is different for Vendors

1. Vendors can only bid on the **current active Line Item**.
   [image: current active line item]
2. Vendors can view upcoming Line Items but cannot take any action on them.
   [image: upcoming line items]
3. Once a Line Item closes, it moves to the **Ended Bidding** category, where no further action is possible.
   [image: Ended Bidding category]
   [image: ended line items]

## Re-opening Line Items — Create Serial Bidding events

1. On the buyer screen, go to **Settings**.
   [image: Settings]
2. Click **Re-Open Line Items**.
   [image: Re-Open Line Items]
3. A Side drawer opens for Reopen Line Items
   [image: Reopen Line Items drawer]
4. Enter the new **duration** for each re-opened Line Item.
   [image: new duration]
5. Select the Line Item(s) you want to re-open.
   [image: select line items]
6. Click **Re-Open** to restart the submission time for those selected items.
   [image: Re-Open button]
