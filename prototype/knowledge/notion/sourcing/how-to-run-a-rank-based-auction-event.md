# How to run a Rank-Based Auction event?

Source: Notion Knowledge Base — How to run a Rank-Based Auction event? (https://app.notion.com/p/94092226c8b28362ae4881e5e7c6274e) · last edited 2026-04-12
Section: Sourcing › Auction

**Persona:** Buyer

This guide explains how a buyer can run and manage a Request for Quotation (RFQ) event on the platform. You should read this after you have created and published your sourcing or stand-alone RFQ event.

## Accessing the RFQ Event — Run a Rank-Based Auction event

1. Navigate to the **Events** tab on the left-hand menu.
   [image: Events tab in the left-hand menu]
2. Find and click on the card for the event that has been published.
   Or Go to any project and navigate to the Auction Tab
   [image: event card]
   [image: project Auction tab]
3. You'll be directed to the Auction Responses tab where vendor quotes can be monitored and managed.
   [image: Auction Responses tab]

## Comparing Vendor Quotes — Run a Rank-Based Auction event

[image: vendor quote comparison]

1. Scroll through the various line items to compare prices submitted by different vendors.
2. The QCS also assigned ranks to each vendor on the Line item level and also next to the Vendor's name.
3. The system will automatically highlight the **L1 (Lowest)** price in green for each line item.
4. A percentage icon next to the bid shows the savings compared to the previous bid submitted by that vendor.
   [image: percentage savings icon]

## Managing Individual Quotes — Run a Rank-Based Auction event

1. Click on the **three-dot menu** next to any vendor's name in their quote to see a **"Reject Bid"** option
   [image: three-dot menu with Reject Bid]
2. Select **Reject Bid** to remove it from the comparison view and the Quote Comparison Sheet (QCS).
   ***Choose whether the Seller is Allowed to bid again or not by checking or unchecking the box***
   [image: Reject Bid dialog with allow-to-bid-again checkbox]

## Reviewing Previous Vendor Bids — Run a Rank-Based Auction event

1. Hover over "Current bid" value to view the vendor's past bids. Select which bid version u would like to jump to.
   [image: Current bid hover with past bids]
2. Use the arrow buttons next to the bid value to cycle through previous revisions submitted by the vendor or go back to the current bid
   [image: arrow buttons next to bid value]

## Sending Counter Offers — Run a Rank-Based Auction event

1. Locate the vendor name in the comparison view.
2. Click the **Counter Offer** button displayed under the vendor name.
   [image: Counter Offer button]
3. You will be taken to the counter offer interface to configure and send your revised expectations to the vendor.
   [image: counter offer interface]

> **Note.** To understand the full flow for counter offers, refer here → (link to the counter offers article)

## Using the Actions Button — Run a Rank-Based Auction event

1. Click the **Actions** button to access advanced controls.
   [image: Actions button]
2. Select **Show Best Prices** to show Suppliers the exact best price for each line item. It also add an extra row for each line item that displays the lowest bid across vendors in the QCS.
   [image: Show Best Prices]
   [image: best price row in QCS]
3. Select **Enable Vendor Masking** to hide the names of all the Vendor's names until bidding ends. Names are replaced with Vendor 1,2,3,4….N.
   [image: masked vendor names]
   ***The participants tab is also hidden***
   [image: participants tab hidden]
4. Select **Enable View-Only Mode** to restrict users from sending counter offers, editing quotes, or placing surrogate bids. You can disable this mode by clicking on the same action again.
   [image: Enable View-Only Mode]
   [image: view-only mode active]

## Sending Bulk Counter Offers — Run a Rank-Based Auction event

1. Click on Settings and find "Send Bulk Counter Offers"
   [image: Settings with Send Bulk Counter Offers]
2. Decide the counter offer you want to send to all vendors and click on Send
   [image: bulk counter offer dialog]

> **Note.** For a detailed walkthrough, refer to the "How to Send Bulk Counter Offers" guide.
