# How to create a Single Stage Event (RFP, RFQ, Auction)?

Source: Notion Knowledge Base — How to create a Single Stage Event (RFP, RFQ, Auction)? (https://app.notion.com/p/daa92226c8b282118fe581522bc01e3e) · last edited 2026-04-12
Section: Sourcing › Creating Events

A Single-Stage Event is a standalone event. These are either RFP (Request for Proposal), RFQ (Request for Quotation), or Reverse Auctions. These Events are not linked to any project or to any other events.

> **Note.** To understand how to create a project, see the article "How to create a Sourcing Project (Technical Stage, RFQ, Auction)?".

## Who Is This For? — Single Stage Event

Buyers, Procurement Managers

## Steps to Create a Single-Stage Event — Single Stage Event

1. Navigate to the **Events** page from the left navigation panel.
   [image: the Events screen]
2. Click on the "+ **New Event**" button.
3. In the panel that opens, choose **"Single Stage"**.

> **Note.** You'll be taken to the event setup screen. By default, the **Event Type** is set to **Rank on Line**, a type of Reverse Auction.

[image: event setup screen with the Rank on Line badge]

4. Click on the **Rank on Line** badge to choose your **Event Type**. This opens a side drawer with 3 options:
   - **RFP (Request for Proposal)**
   - **RFQ (Request for Quotation)**
   - **Reverse Auction**

> **Note.** Each event type has its own configurations:

| Event Type | Required Configurations |
|---|---|
| **RFP** | No Configurations required |
| **RFQ** | Awarding Type (Lot or Line), Delivery Date (optional) |
| **Reverse Auction** | Auction Strategy (Rank Based, Price Bases, Traffic Light, Knockout, Dutch), Awarding Type (Lot or Line), Rank Type Configurations (optional), Serial Bidding (optional) |

> **Note.** To learn more about Auction Strategies, Serial Bidding, or individual event types, see the related Knowledge Base articles.

5. Click on Select Template.
6. Choose a predefined **template** based on your use case.

> **Note.** Want to understand how to create templates? See the related Knowledge Base article.

7. Add **products/items** for which you're seeking bids by clicking on the cell beneath the "Products" column and selecting from the dropdown. You can also type in the cell to narrow your search.
   - You can add more products in each subsequent row. (A new row will automatically be added each time)
   - There is a limit of up to 65 line items for this.
8. Fill in all **mandatory fields** in the template table. Quantities are free text. However, some fields, such as location, will be dropdowns similar to those for products (e.g., quantity, location, etc.).

> **Note.** Shaded out fields that can't be filled in are for the Vendor to fill. Buyer's cannot fill in these fields.

9. The Procol platform suggests Vendors mapped to the products added by you in the above template. Click on the blue "Invite Vendors" shown in the green tip to automatically add them as participants.
10. You can search, filter, or add vendors manually as well by clicking on Participants. The below screen shows up.
    [image: Participants screen]

> **Note.** Procol auto-generates the event title using product and location names, but you can edit this as needed.

11. Click on the Blue "Publish Event" button.
12. In the Pop-up screen, review all the Event details. If everything seems in order, you can click on the blue "Publish" button. This will send an email notification to all added participants, inviting them to participate in the event that is now Live.
    *Alternatively, you can press "Edit Schedule" to schedule the event for later.*

> **Note.** **You Have Successfully Published your Event !!** [image: published event confirmation]

## Optional Steps and Best Practices — Single Stage Event

[image: bottom-left event options — Terms & Conditions, Savings, Edit Currencies, Schedule]

- **Click on Terms & Conditions** to add pre-saved or custom T&C that will be shown to the participating Vendors. (Learn more: "How to add Terms and Conditions for my Vendors in my Events?")
- **Click on Savings** to configure savings references. (Learn more: "How to set Savings references in an Event?")
- **Click on Edit Currencies** to edit the base or have multiple currencies. (Learn more: "How to Edit Currencies in my Event")
- **Click on Schedule** to schedule the event for a later date and time or to change the duration of the event. (Learn more: "How do I Schedule Events and change Event Duration?")

[image: template toolbar — + Add Columns and Upload Sheet]

- **Click on "+ Add Columns"** to add custom Columns to the template for this event specifically. (Learn more: "How do I add additional columns to a Template?")
- **Click on "Upload Sheet"** to fill the template details via uploading an excel sheet. (Learn more: "How do I fill my tempate by uploading an Excel Sheet?")
