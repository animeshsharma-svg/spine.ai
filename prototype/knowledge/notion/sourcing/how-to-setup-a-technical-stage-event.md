# How to setup a Technical Stage Event?

Source: Notion Knowledge Base — How to setup a Technical Stage Event? (https://app.notion.com/p/54492226c8b282f3906301d6cbfe2ca2) · last edited 2026-04-12
Section: Sourcing › RFP / Technical Stage

The Technical Stage is the phase where vendors submit **product specifications**, **certifications**, and other technical details for your evaluation. This stage ensures that only technically compliant vendors move forward to the commercial evaluation.

## Steps — Setup a Technical Stage Event

1. Click on Technical Stage to review it as well
   [image: Technical Stage]
2. Click on Select Template to apply an RFP Template for all the Line Items via Bulk Action.
   [image: Select Template bulk action]

> **Note.** You can see that for all line items the same template has been applied

[image: same template applied to all line items]

3. Click on select template under the "Vendor Assessment" Section.
   [image: Vendor Assessment select template]
4. Click on "+ Add Evaluator" under the first line items
   [image: + Add Evaluator]
5. Search the user you want to assign as the technical evaluators.
   Repeat the same action for the all line items without fail.
   [image: evaluator search]

> **Note.** Technical Evaluators are users who will assess the quality of the goods provided by a vendor basis the responses of the vendor in this stage. He can assigns ranks (T1, T2, T3) or (TA - Technically Accepted or TNA - Technically Not Accepted)
