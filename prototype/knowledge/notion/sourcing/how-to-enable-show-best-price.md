# How to enable Show Best Price?

Source: Notion Knowledge Base — How to enable Show Best Price? (https://app.notion.com/p/1dd92226c8b283428cf781dc0f0b52ab) · last edited 2026-04-12
Section: Sourcing › Others

The *Show Best Price* feature allows buyers to display the current lowest bid (best price) submitted for any line item directly on the QCS. This ensures transparency for vendors, enabling them to see the price they need to beat to become L1 (lowest bidder).

## Persona — Show Best Price

Buyer, Auction Owner, Sourcing Manager

## Steps to Enable and Use Show Best Price — Show Best Price

1. Click the **Actions** button to access advanced controls.
   [image: Actions button]
2. Select **Show Best Prices** to show Suppliers the exact best price (lowest / L1 bid) for each line item. It also adds an extra row for each line item that displays the lowest bid across vendors in the QCS.
   [image: QCS with the best price row per line item]

- This column is visible to both buyers and participating vendors.
- Vendors can use this information to update their bids competitively.
  [image: vendor view showing the best price]
