## Steps to Enable Serial Bidding — Run a Traffic Light Auction

(The heading is as written in Notion; the steps below set up a Traffic Light auction.)

1. Create a new event in Procol.
   [image: create new event]
2. In the **Event Type** dropdown, select **Auction**.
   [image: Event Type dropdown]
   [image: Auction selected]
3. Select The "Traffic Light" Auction Strategy
   [image: Traffic Light strategy]
4. Choose the grouping condition
   [image: grouping condition]
5. Make sure awarding is on the entire lot.
   [image: awarding on entire lot]
6. Configure the ranges.
   [image: traffic light ranges]
7. Click on Save and Publish the Event
   [image: Save and Publish]
8. After all the vendors have published the traffics lights have been assigned based on the conditions set by you
   [image: buyer view with traffic lights]
9. Vendors are able to see which zone they are currently in as well, and can only do trial and error to get out of the zone in to a safer zone like green and yellow.
   [image: vendor view with zone]
10. You have the option to show Best price and Rank in the traffic light auction as well.
    [image: show Best price and Rank options]
