# How to Raise a Material Creation Request via Intake

Source: Notion Knowledge Base — How to Raise a Material Creation Request via Intake (https://app.notion.com/p/82192226c8b28291bfc6814887cc47c9) · last edited 2026-04-12
Section: P2P › Intake & Request Creation

**Description:**
Intake requests empower end users to raise structured requests for various procurement actions like purchases, contracts, or master data changes. This guide explains how to raise an intake request to create a new material in the material master, which, once approved, is added to the system by a designated team member.

**Persona:**
**Requestors / End Users / Operations / Planning Teams** – Users responsible for raising master data or purchase-related requests to initiate procurement or system actions.

## Step-by-Step Process — Raise a Material Creation Request via Intake

1. Navigate to the **"Intake"** page using the left-side navigation panel.
   [image: the Intake page in the left-side navigation]
2. Click on the **"Create Request"** button to begin a new request.
   [image: the Create Request button]
3. On the Create Intake Request page:
   [image: the Create Intake Request page]
4. Enter a **Request Title** (e.g., "Add New Raw Material - HDPE Granules").
   [image: the Request Title field]
5. Select the **Request Condition** as **"Material Creation"**.
   [image: the Request Condition selector with "Material Creation"]
6. Click **"Next"** to proceed to the **Basic Details** section.
   [image: the Next button]
7. Fill out the required fields for material creation:
   [image: the material creation fields]
   - **Item Description** – Name of the material
   - **Item Type** – Choose between "Material" or "Service"
   - **Unit of Measure** – Select from the dropdown (e.g., KG, NOS)
   - **Category and Subcategory** – Choose the relevant categories for classification
   - **Material Code (optional)** – If applicable, input or leave blank to be generated later
8. (Optional) To add more than one material, click on the cell in the next row and repeat the above steps for each item. *A new blank row will be added everytime.*
   [image: a new blank row added]
9. You can delete some products / rows by clicking the **Red Bin icon** to delete the row.
   [image: the red bin icon on a row]
10. Once all entries are complete, click **"Next"** to review the **Approval Workflow**.
    [image: the Approval Workflow step]
11. The system automatically assigns the approval chain based on selected categories or item details. Review and confirm.
    [image: the auto-assigned approval chain]
12. Click **"Next"** to submit the intake. The approval workflow is now triggered.
    [image: the final Next/submit button]

> **Note.** Upon approval, the material will be added to the system by the relevant team or system integration process.

> **Note.** To understand how an Intake Request is Approved go to 👉 [linked article: How to Approve and Complete an Intake Request]
