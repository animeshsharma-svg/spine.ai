# Creating an Intake Request (P2P)

Source: Notion Knowledge Base — Creating an Intake Request (P2P) (https://app.notion.com/p/21692226c8b283279eb4810c63ab49df) · last edited 2026-04-12
Section: P2P › Intake & Request Creation

**Description:**
One of the most frequently used intake flows on Procol, the Purchase Intake Request allows end users to raise a structured request to initiate a purchase process directly—without relying on email or manual intervention from the procurement team. Once submitted and approved, this automatically creates a purchase request in the system.

**Persona:**
**End Users / Requestors / Departmental Teams / Operations / Admin / Planning** – Anyone in the organization looking to initiate a purchase through the proper channel.

## Step-by-Step Process — Creating an Intake Request (P2P)

1. Navigate to the **"Intake"** page using the left-side navigation panel.
   [image: the Intake page in the left-side navigation]
2. Click on the **"Create Request"** button to begin a new request.
   [image: the Create Request button]
3. On the Create Intake Request page:
   [image: the Create Intake Request page]
4. Enter a **Request Title** (e.g., "Add New Raw Material - HDPE Granules").
   [image: the Request Title field]
5. Select the **Request Condition** depending on which Request you intend to raise, we are raising the "New Activity"
   [image: the Request Condition selector with "New Activity"]
6. Click **"Next"** to proceed to the **Basic Details** section.
   [image: the Next button]
7. Click **"Next"** to proceed to the **Details Page**.
   [image: the Details page]
8. In this section:
   - Select the **Currency** for the purchase.
   - Fill in additional custom fields if available (these may vary based on organization-specific configurations).
   [image: currency and custom fields]
9. Scroll to the **Product Details** section:
   [image: the Product Details section]
   - Search and select the **Product Name** (which auto-fills the Product Code).
   - Enter **Quantity** and choose the correct **Unit of Measure**.
   - Select the **Delivery Location**.
   [image: a filled product row]
   - To add more than one material, click on the cell in the next row and repeat the above steps for each item. *A new blank row will be added everytime.*
   [image: a new blank row added]
10. You can delete some products / rows by clicking the **Red Bin icon** to delete the row.
    [image: the red bin icon on a row]
11. (Optional) Fill out any additional sections such as **Vendor Information** or **Budget Information**, based on your form setup.
    [image: Vendor Information section]
    [image: Budget Information section]
12. Click **"Next"** to view the **Approval Workflow**, which is auto-determined based on category, department, or configuration.
    [image: the Approval Workflow step]
13. The system automatically assigns the approval chain based on selected categories or item details. Review and confirm.
    [image: the auto-assigned approval chain]
14. Click **"Next"** to submit the intake. The approval workflow is now triggered.
    [image: the final Next/submit button]

> **Note.** Once approved, the system will automatically generate a **Purchase Request**, enabling the procurement process to proceed in Procol.

> **Note.** To understand how an Intake Request is Approved go to 👉 [linked article: How to Approve and Complete an Intake Request]
