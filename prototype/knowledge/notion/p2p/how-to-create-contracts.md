# How to create Contracts

Source: Notion Knowledge Base — How to create Contracts (https://app.notion.com/p/cab92226c8b28262bd1c01329f677574) · last edited 2026-04-12
Section: P2P › Contracts

In this knowledge base page, you will learn how to create contracts. They can be defined based on various variables such as department, location, or branch. You can also track allocated budgets, spending, and balances, as well as manage updates and approvals.

## Step-by-Step Process — Create Contracts

1. Navigate to the Contracts page using the **left-side navigation panel**.
   [image: Contracts in the left-side navigation]
2. On the Contracts page,
   [image: the Contracts page]
3. To create a new contract, click the **+ New** button.
   [image: the + New button]
4. On the **Contract** page, fill in the required details:
   [image: the Contract creation page]
   - Contract ID (Text)
   - Contract Name (Text)
   - Draft Status (Dropdown)
   - Start Date (Calendar select)
5. Click **Show More** to reveal additional customizable fields.
   [image: the Show More control]

> **Note.** The article ends here in Notion; it does not describe saving, submitting or approving the contract.
