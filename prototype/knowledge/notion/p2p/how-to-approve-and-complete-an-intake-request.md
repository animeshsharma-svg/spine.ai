# How to Approve and Complete an Intake Request

Source: Notion Knowledge Base — How to Approve and Complete an Intake Request (https://app.notion.com/p/6de92226c8b282fa99c80193cfd223fe) · last edited 2026-04-12
Section: P2P › Intake & Request Creation

**Description:**
Once an intake request is submitted on Procol, it automatically triggers an approval workflow based on predefined organizational policies. These policies may consider request categories, line items, departments, or custom logic. This guide helps explain how approvers can review, approve, or reject intake requests, and what happens after all approvals are completed.

**Persona:**
**Approvers / Department Heads / Budget Owners / Procurement Leads** – Anyone responsible for reviewing and approving intake requests.

## Step-by-Step Process — Approve and Complete an Intake Request

1. Once an intake request is submitted, it triggers an **Approval Workflow** automatically.
   [image: the approval workflow on a submitted intake]
2. The workflow is selected based on logic such as request category, line items, or organizational policy.
3. A **visual flowchart** appears, displaying:
   - The name of the user who created the intake.
   - The current approver(s).
   - If there are multiple levels of approval, each will appear in sequential order.
   [image: the visual approval flowchart]
4. As an **Approver**, you will:
   - See the intake request with the option to **Approve** or **Reject**.
   - Have a field to enter **Remarks** or **Comments** (optional but encouraged).
   [image: Approve / Reject options with a remarks field]
5. After taking action:
   - The workflow will update in real-time to show who approved/rejected and the **timestamp**.
   - Any **remarks** will be visible in the **Comments** tab on the right.
   [image: the updated workflow with approver and timestamp]
   [image: the Comments tab]
6. If all approvals are completed:
   - If the intake was created to initiate a **Purchase Request**, then:
     - The system automatically generates a Purchase Request within minutes.
       [image: the generated Purchase Request]
     - A **hyperlink to the Purchase Request** appears on the workflow chart.
       [image: the Purchase Request hyperlink on the workflow chart]
     - Clicking the link opens the Purchase Request detail page directly.
       [image: the Purchase Request detail page]

> **Note.** The intake request is now considered **complete** and closed in the system.
