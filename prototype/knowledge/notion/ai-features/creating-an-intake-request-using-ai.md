# Creating an Intake Request using AI

Source: Notion Knowledge Base — Creating an Intake Request using AI (https://app.notion.com/p/98b92226c8b282d2bdf8018a8b4dd978) · last edited 2026-04-12
Section: AI Features

**Description:**
Intake Requests serve as a powerful entry point for end-users to initiate various procurement-related actions. Whether it's for purchasing items, creating contracts, or onboarding new materials, the AI-powered Intake process ensures a seamless and intelligent way to capture details and kick off the right workflows without needing predefined templates.

This guide walks you through how users can use AI to raise intake requests by simply describing what they need, and letting the system guide them through follow-up questions.

**Persona:**
**End Users / Requisitioners / Internal Requestors** – Team members or stakeholders who initiate needs for procurement, contracts, or material onboarding.

## Step-by-Step Process — Creating an Intake Request using AI

1. Navigate to the **Intake** page from the left-hand menu.
   [image: Intake page]
2. Click on the **"+ Create Intake AI"** button at the top-right corner of the screen.
   [image: "+ Create Intake AI" button]
3. A new page opens with a text box and a prompt: **"What do you want to buy?"**
   [image: "What do you want to buy?" prompt]
4. Type your request in plain English. For example: `"I want to buy 100 laptops."`
   [image: request typed in the text box]
5. Click on **"Next."** The system now begins analyzing your input and fetching follow-up questions using AI.
   Now the System will use AI to fetch related questions to ask the user to understand the purchase request further.
   [image: AI analysing the request]
6. The AI will prompt for basic purchase details relevant to your request. For laptops, some examples include:
   - Laptop model or brand
   - Quantity
   - Delivery location
   - Budget
   [image: basic purchase detail questions]
7. Click **"Next"** to proceed once you've filled in the initial details.
8. The system will then ask more technical specifications based on your item. Continuing the laptop example:
   - RAM size (e.g., 16GB, 32GB)
   - Processor type (e.g., Intel i7, AMD Ryzen 5)
   - Storage capacity (e.g., 512GB SSD)
   [image: technical specification questions]
9. It may also ask operational or support-related questions such as:
   - Warranty type (standard, extended, or on-site)
   - Support service preferences
   [image: operational/support questions]
10. Additional fields may appear as:
    - Optional notes or descriptions
    - Attachments or supporting documents
    [image: notes and attachments fields]
11. Once all required inputs are collected, you can choose to review or go back to edit.
12. Click **"Submit"** to finalize the intake request.
    [image: Submit button]
13. Upon submission the AI Builds searches for an Approval Workflow best suited to this purchase.
    [image: AI searching for an approval workflow]
14. An **Approval Workflow** is automatically triggered based on your organization's rules.
    [image: approval workflow triggered]
15. Once approved, a **Purchase Request (PR)** is generated automatically from this intake request.
    [image: PR generated from the intake]
16. You can now see that the PR is created and in Open State.
    [image: PR in Open state]
17. Click on the Blue Icon to see the PR Details page of the PR that has just been created.
    [image: blue icon linking to PR Details]
    [image: PR Details page]

> **Note.** You have successfully created an Intake Request using AI to create a PR! This AI-based process eliminates the need for pre-configured forms and templates, helping organizations scale intake across multiple use cases while reducing manual setup for intake templates. The AI dynamically determines what it needs to ask based on the initial user input.
