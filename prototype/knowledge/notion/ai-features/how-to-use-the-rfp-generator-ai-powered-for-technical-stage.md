# How to Use the RFP Generator (AI-Powered) for Technical Stage

Source: Notion Knowledge Base — How to Use the RFP Generator (AI-Powered) for Technical Stage (https://app.notion.com/p/85492226c8b28282a6b801250a4be346) · last edited 2026-04-12
Section: AI Features

**Description:**
The RFP Generator is a powerful AI-powered feature that helps buyers automatically generate relevant technical questions for vendor assessments and line items based on historical data and product descriptions. By enabling the RFP Generator during the Technical Stage of your sourcing project, you can quickly create tailored RFPs that save time and improve the quality of vendor responses.

**Persona:**
**Buyer / Purchaser** – Responsible for initiating sourcing projects and creating RFPs to gather detailed technical inputs from vendors.

## Step by Step Process — RFP Generator (AI-Powered)

> **Note.** On the Purchase Request page…

[image: Purchase Request page]

1. **Select** the checkbox next to each PR line item you want to process. You can select multiple at a time!
2. Click the blue **🛒 "Purchase Items"** button on the top right. (It shows the number of how many items that have been selected)
3. A **side panel** will slide open, showing all selected items along with their respective quantities.
4. Click the blue **"Create Project"** button on the bottom right, to go ahead with processing these Line items. (It shows the number of how many items that have been selected)
5. Here, you are given the option to select which events you want to create as a part of your Sourcing Project. Make sure to select **"Technical Stage", to be able to access the RFP Generator**.
6. After selecting the type of events you need, you can click on **"Create Project"** again to start setting up your Events.
7. Now you would land on the Event Creation page where you would be able to set up your Technical stage.
   [image: Event Creation page]
8. Click on the "Event Type" where **"Technical Stage >"** is showing.
9. A Side panel opens for configuring your Technical Stage settings.
10. Select the **"Generate question using AI"** under *"How will you create a Technical Stage?"*
11. Click on **"Save"**.
12. The system will now automatically start generating technical questions using AI based on the line items you've added. It references past events and online data to determine the most relevant questions for vendor assessment and product evaluation.
    [image: AI generating technical questions]
    [image: generated Vendor Assessment and Line Item questions]
13. Click on the Green AI Icon to open the AI Chat Interface.
14. A Side panel for the Chat opens, with some Suggested Actions, and a Textbox to type a custom instruction.
15. You can choose which section to apply the changes to, whether it's **Vendor Assessments** or **Line Items**.
16. Type in the instructions or prompt, or you can use one of the Suggested Actions.
17. Click on the **Send** button or hit Enter.
18. Now the system is using AI to make the changes according to your prompt for the desired section.
    [image: AI applying changes]
19. Here you can see that the changes have been made!
    [image: updated questions after the prompt]
20. Now you have the option to give it more prompts to further refine your prompts, or you can "Undo Changes".
    [image: "Undo Changes" option]
21. To go into fullscreen mode you can close the chat screen by pressing on the ❌.

> **Note.** You have successfully created an RFP using AI!
