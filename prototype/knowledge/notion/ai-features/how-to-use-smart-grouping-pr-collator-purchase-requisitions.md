# How to Use Smart Grouping (PR Collator) on the Purchase Requisitions Page

Source: Notion Knowledge Base — How to Use Smart Grouping (PR Collator) on the Purchase Requisitions Page (https://app.notion.com/p/1d692226c8b282f3a96c81f187fb9d0c) · last edited 2026-04-12
Section: AI Features

**Description:**
Smart Grouping, also called the PR Collator, is a powerful AI-driven feature that helps buyers automatically group similar purchase requisitions based on different criteria such as product category, delivery location, or quantity. It simplifies PR management and enables faster processing by intelligently organizing requisitions that can be processed together. With built-in grouping modes and Procol AI chat support, users can control how strict or flexible the grouping logic should be.

**Persona:**
**Buyers / Procurement Executives / Planning Teams** – Users responsible for processing large volumes of PRs and who want to streamline their workflow by grouping related requisitions.

## Step-by-Step Process — Smart Grouping (PR Collator)

1. Navigate to the **Purchase Requisitions** page on the Procol platform.
   [image: Purchase Requisitions page]
2. Locate the **"Smart Grouping"** button towards the middle-right side of the screen, just above the PR table.
   [image: Smart Grouping button]
3. Click on **Smart Grouping.** A side panel will open with a chat interface powered by **Procol AI**.
   [image: Smart Grouping side panel]
4. In this panel, you'll see a set of recommended grouping prompts, such as:
   - Group by product category
   - Create balanced groups
   - Group by delivery location
5. Below these suggestions, you'll find a **chat input box** where you can type in custom grouping rules or instructions.
   [image: chat input box]
6. Use the **Grouping Mode** dropdown to choose how strict the AI should be in forming groups:
   - **Basic:** Loosely groups similar PRs with flexibility.
   - **Balanced:** A mix of flexibility and strictness.
   - **Strict:** Only identical PRs are grouped together.
7. Select a recommended prompt (e.g., **Group by Product Category**) by clicking on it. This action pastes the relevant instruction into the AI chat input box.
   [image: recommended prompt pasted into the chat input]
8. Click on the **blue send icon** to submit the grouping request.
9. The system will now process your request. After a few seconds, the AI will return a response with:
   - Grouping logic explanation
   - Conditions being applied for grouping
   [image: AI response with grouping logic and conditions]
10. Review the output:
    - To make changes, click on **Modify Conditions** to re-edit and re-send the prompt
    - If satisfied, click on **Apply Grouping**
11. Once applied, your PR table will be updated with new **Smart Groups** based on the AI's response.
12. To close the Smart Grouping panel, click the **"X" icon** on the top-right of the side panel.
    [image: PR table showing Smart Groups]
13. To remove the applied grouping and return to the original PR view, click on the **"Remove Grouping"** text located just beside the Smart Grouping button.
    [image: "Remove Grouping" text beside the Smart Grouping button]
