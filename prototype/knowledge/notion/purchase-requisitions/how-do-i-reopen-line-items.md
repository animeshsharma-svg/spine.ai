# How do I reopen Line Items?

Source: Notion Knowledge Base — How do I reopen Line Items? (https://app.notion.com/p/62f92226c8b282a1ade381c217625873) · last edited 2026-04-12
Section: Sourcing › Purchase Requisitions

If a PR line item has been put on Hold, and needs to be brought back into an Open state so that you can start processing it.

### How to Reopen a PR Line Item — Reopen Line Items

1. Navigate to the Hold Status Tab of the PR Page.
   [image: the Hold status tab of the PR page]
2. Scroll to the far right of the PR table.
3. Click on the ♻️ **"Re-open Item"** button for the relevant PR line item.
   [image: the Re-open Item button on a held line item]
4. Read the message and Confirm the action by clicking on the blue **"Reopen Item"** button.
   [image: the reopen confirmation message with the Reopen Item button]
5. You can view the Items that you reopened in the Open Status Tab of the PR page.
   [image: the PR status tabs]

> **Note.** Once reopened, this item will be available for buying again. The Requisitioner responsible for this item will get notified about this action.
