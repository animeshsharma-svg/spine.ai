## Purchasing Items — Start Processing my PRs

The **Purchase Cart** allows buyers to select one or more PR line items they intend to process. Think of it as a cart you can review, edit, and adjust before you get into creating sourcing events.

### How to Add Items to the Cart — Start Processing my PRs

1. **Select** the checkbox next to each PR line item you want to process. You can select multiple at a time!
   [image: PR line items selected with checkboxes]
2. Click the blue **🛒 "Purchase Items"** button on the top right. (It shows the number of how many items that have been selected)
   [image: the Purchase Items button with the selected-item count]
3. A **side panel** will slide open, showing all selected items along with their respective quantities.
   [image: the cart side panel with selected items and quantities]
4. Click the blue **"Create Project"** button on the bottom right. To go ahead with processing these Line items. (It shows the number of how many items that have been selected)
   [image: the Create Project button with the selected-item count]
5. Here, you are given the option to select which events you want to create as a part of your Sourcing Project. After selecting the type of events you need, you can click on **"Create Project"** again to start setting up your Events.
   [image: selecting the event types for the Sourcing Project]

> **Note.** The cart helps you organize your selected items before proceeding with further procurement steps like creating an Technical Stage/ RFQ/ Reverse Auction or PO.

### 🛒 Cart Behaviour — Start Processing my PRs

- **Quantities are editable** directly within the cart. Click on the quantity box and type in a new value.
  [image: editing a quantity in the cart]
- The **edited quantity cannot exceed** the originally requested quantity from the PR.
- You can **remove items** from the cart by clicking the **🗑️ trash icon** next to each line.
- You cannot change the UOM of the Qty at this stage.
  [image: cart line with the trash icon]
