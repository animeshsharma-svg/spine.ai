## Introduction — Tour of the PR Page

For Integrated Clients, these appear via a seamless integration with your existing ERP (Like SAP's S4 Hana). Whenever a PR is raised on your ERP, it automatically reflects on Procol's PR page.

## What are PR Status — Tour of the PR Page

There are 4 statuses under which PR Line Items can fall. You can navigate between these tabs to track their status and progress.

[image: the four status tabs on the PR page]

| Status | Meaning |
| --- | --- |
| **Open** | No Events have been created for this PR Line Item |
| **In Progress** | Events have been created for this PR Line Item. |
| **Completed** | The Quantity for which the PR has been raised for the Line Item has been fulfilled |
| **Hold** | The PR Line Item has been placed on Hold, No events can be created for it until it is taken out of Hold. |

## Assigning PRs to your team — Tour of the PR Page

You can assign line items to your team members to make them responsible for executing these purchases. They must make sure they create Events and move these PRs from Open to Completed.

### How to do this? — Tour of the PR Page

You Can Hover over the "+" icon in the Assignee column. You can then see an Add Assignee option appear.

[image: the "+" icon in the Assignee column]
[image: the Add Assignee option]

You can also add assignees through bulk action for multiple line items.

You can select multiple PR Line Items and then click on the Add Assignee button on the top right.

[image: multiple PR line items selected]
[image: the Add Assignee button at the top right]

In both Bulk and Individual Actions, once "Add Assignee" is clicked, a scrollable dropdown is opened where you can select the Assignee. You can also search for a user by typing in the search bar.

[image: the scrollable assignee dropdown with a search bar]

## Filters Functionality in the PR Page — Tour of the PR Page

To make your day easier, we included extensive filter options so you can filter items from different PRs and create a common event to process them further. This makes finding the right PR Line items easy.

If you want to revert the page back to how it was before, you can click on the "🗑️ Clear Filter" button. This will clear all the filters and revert the page to its original state.

[image: filter options and the Clear Filter button]

The Best part, these filters persist until you clear them. Even when you switch between different pages and modules of the platform.

## Hiding Columns in the PR page — Tour of the PR Page

When you click on "👁️ Columns (N/N)" button, a window opens where you can see all the columns present in your PR Line item table.

[image: the Columns window listing the PR table columns]

This feature gives you complete control over your visibility, with easy options to "Hide All" and "Show all" to revert whatever has been hidden. These settings also persist until you change them. Even when you switch between different pages and modules of the platform.

### Exporting your PRs — Tour of the PR Page

With the single click of a button, you can export all your PR Line items and their details from the platform. This export report is sent to your email as an excel document (.csv /.xlsx format)
