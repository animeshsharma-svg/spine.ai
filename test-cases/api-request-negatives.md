Generated by `prototype/scripts/build-api-assertions.ts` from the request bodies the API journey actually sends. Each case mutates ONE field of a real, working request and expects the app to refuse it cleanly (4xx, nothing created or changed) rather than accept bad data or break (5xx). Run against a sandbox event only.
